# AI辅助医学教学系统 (MedTeach) 技术方案

## 一、项目定位

- **全新独立项目**（非 MedAiAssistant 模块），独立前后端与数据库
- **目标用户**：医学本科生 → 住院医师/规培生 → 主治医师，多层级兼容
- **数据来源**：直连医院 Oracle HIS 数据库（只读），内置脱敏→导入教学库
- **MVP 范围**：病例脱敏导入 + 教案生成（含AI审查+PPT） + 临床思维教学（诊断思维+诊疗方案思维） + 课后题目演练 + 教学评估与个性化推荐 + 现场教学讨论

## 四、核心模块设计

### 4.1 病例脱敏导入
- PII检测：正则(身份证/手机/医保号) + HanLP NER(姓名/地名/机构名)
- 脱敏策略：姓名保留姓氏(张**)，去掉手机号、地址身份证号等个人信息
- 映射表AES加密存储(仅审计追溯)，严格权限控制
- Oracle只读数据源 → 异步任务导入 → 达梦DM8教学库

### 4.2 教案自动生成（含PPT + AI审查 + 专利点）
- **分阶段生成**：病例分析提取 → 教案结构生成 → PPT大纲生成 → 内容润色
- **AI自动审查**：生成后由独立AI角色进行医学准确性、教学逻辑性、内容完整性三重审查，输出审查报告（通过/需修改/驳回+修改建议）
- **PPT大纲+自动生成**：教案生成后同步输出PPT大纲（含每页标题、要点、病例素材引用），可接入PPT API（如Apache POI / Aspose.Slides）一键生成.pptx文件
- LangChain4j @StructuredOutput 确保JSON Schema约束
- 不同角色加载不同难度Prompt模板
- SSE推送生成进度，教案草稿→AI审查→教师审核→发布
- **专利点**：① AI双角色生成+审查机制（生成AI与审查AI独立Prompt，交叉验证医学准确性）② 病例→教案→PPT大纲三级联动自动生成方法

### 4.3 临床思维教学（双模块 + 专利点）

临床思维教学分为两个独立子模块，均基于现有临床逻辑推理规则生成教学步骤：

#### 4.3.1 诊断思维教学
- **推理引擎**：基于临床诊断推理逻辑（症状→体征→鉴别诊断→确诊），AI驱动分步教学
- **教学流程**：主诉分析 → 病史追问要点 → 体格检查选择 → 辅助检查合理选择 → 鉴别诊断排序 → 最终诊断确认
- **教学要点**：每步提供临床推理依据，学生需阐明选择理由，AI评估推理过程而非仅看结果
- 角色差异化：本科生侧重常见病诊断路径、住院医师侧重鉴别诊断广度、主治医师侧重罕见病和复杂共病

#### 4.3.2 诊疗方案思维教学
- **推理引擎**：基于诊疗计划逻辑推理（8步骤链式推理），AI驱动分步教学
- **教学流程**：基于上述推理链，AI自动编排教学步骤，每步展示推理依据+治疗方案选项，医生审批节点转为教学讨论点
- **教学要点**：强调指南遵循+个体化决策平衡，学生可在每个推理节点观察AI的临床决策过程
- 角色差异化：本科生侧重理解推理流程、住院医师侧重参与方案展开和风险评估、主治医师侧重逆向审视和复杂共病综合决策

- **专利点**：③ 基于临床逻辑推理链的诊断思维教学步骤自动生成方法 ④ 基于诊疗计划8步推理引擎的诊疗方案思维教学路径自动生成方法

### 4.4 课后题目演练（含AI审查 + 专利点）
- 支持5种题型：单选/多选/判断/病例分析/简答
- Few-Shot + 题型模板 Prompt策略
- **AI自动审查**：题目生成后由独立AI角色进行题干准确性、答案正确性、解析合理性三重审查
- **三级审核流程**：AI生成 → AI自动审查 → 教师人工审核 → 保存入库
- 自动批改 + AI解析
- 根据评估结果推荐个性化练习集
- **专利点**：⑤ 基于AI双角色生成审查+教师确认的医学教学题目三级质量保障方法

### 4.5 教学评估与个性化推荐（含AI综合推荐 + 专利点）
- **多维评估**：诊断逻辑/检查选择/治疗方案/临床知识/学习效率
- **AI评估报告**：优势分析+薄弱环节识别+成长轨迹可视化
- **个性化推荐引擎**：从数据库调取学生全部既往表现数据（诊断正确率、治疗决策评分、题目正确率、讨论参与度等）→ AI综合分析能力图谱 → 根据薄弱环节生成针对性学习推荐（推荐病例/练习/知识模块）
- 连续追踪：学习曲线绘制，评估进步幅度
- **专利点**：⑥ 基于AI多维能力图谱的医学教学个性化学习路径推荐方法

### 4.6 现场教学讨论（含AI三级审核 + 声纹技术 + 专利点）
线下办公室/教室面对面讨论，系统作为教师的辅助工具：

**课前准备阶段：**
- 教师选择病例，AI根据病例实时生成教学讨论提纲（含引导问题、关键讨论点、预期辩论方向、分层讨论线索）
- AI自动审查提纲的医学准确性+教学逻辑性
- 教师最终审核确认后方可使用
- **专利点**：⑦ 基于病例特征AI双角色生成审查的医学教学讨论提纲自动生成方法

**课中辅助阶段：**
- 大屏/投影展示：病例摘要、关键检查结果、影像资料等
- 教师可逐步揭示病例信息（模拟真实诊疗的信息递进）
- 教师记录学生发言要点（快速标记：正确/存疑/需补充）
- **声纹识别技术**：通过麦克风阵列采集学生发言，声纹分离识别每个学生的发言内容、发言时长、提问频次、应答速度，自动生成课堂参与度数据
- **专利点**：⑧ 基于声纹分离的课堂讨论学生表现个性化采集与AI学习建议生成方法

**课后总结阶段：**
- 基于现场讨论记录，AI辅助润色和结构化为正式纪要
- AI自动审查纪要的医学内容准确性
- 教师最终审核后发布到教学库，学生可查看复习
- AI根据声纹采集的个性化数据+教师标记，生成每位学生的课堂表现评估和个性化学习建议
- **专利点**：⑨ 基于AI生成审查+教师确认的医学教学讨论纪要三级质量保障与发布方法

## 九、验证方式

1. **脱敏导入验证**：选择真实Oracle病例执行导入 → 检查teaching_case表中PII字段已替换 → 确认deidentify_mapping加密存储正确
2. **教案生成验证**：选择不同角色(本科/住院/主治)生成教案 → 检查输出JSON Schema完整性 → 教师审核内容准确性
3. **临床思维验证**：诊断思维模块：模拟学生完成症状→诊断推理全流程 → 验证推理链合理性；诊疗方案思维模块：模拟学生完成方案选择→个体化调整 → 验证决策树逻辑和对比教学效果
4. **题目生成验证**：生成各题型题目 → 人工审核答案准确性 → 模拟提交验证自动批改
5. **评估验证**：生成评估报告 → 验证雷达图数据正确 → 验证推荐练习与薄弱环节匹配
6. **现场讨论验证**：教师创建讨论→AI生成讨论提纲→课中标记学生发言→课后AI润色纪要→验证参与度评估
7. **端到端测试**：Cypress录制完整教学流程(导入→备课→教学→评估)

## 十、专利产出规划

本系统预计可产出 **7-9项发明专利**，核心创新点：

### 专利点①：AI双角色生成与审查机制
- **技术方案**：教案生成AI与审查AI使用独立Prompt模板和独立LLM调用，生成AI负责内容创作，审查AI从医学准确性、教学逻辑性、内容完整性三个维度进行交叉审查，输出结构化审查报告
- **创新性**：不同于单次生成+人工审核，采用双AI角色对抗式质量把关，自动发现并修正生成内容中的医学错误和教学逻辑缺陷
- **应用场景**：医疗教育内容自动生成、医学考试命题、临床指南解读等需要高准确性AI生成内容的场景

### 专利点②：病例→教案→PPT大纲三级联动自动生成方法
- **技术方案**：从原始脱敏病例出发，经过三层递进式生成：病例关键信息抽取 → 结构化教案（含教学目标/重点难点/教学过程）→ PPT大纲（含每页标题/要点/病例素材自动引用），层间通过JSON Schema约束保证数据传递一致性
- **创新性**：实现从原始临床数据到可直接用于课堂教学的完整教案+PPT的端到端自动生成，各层级输出互相引用、可追溯至原始病例
- **应用场景**：医学教育备课自动化、学术会议课件生成、继续教育材料制作

### 专利点③：基于临床逻辑推理链的诊断思维教学步骤自动生成方法
- **技术方案**：将临床诊断推理逻辑（症状→体征→鉴别诊断→确诊）形式化为可编排的推理链规则，AI根据具体病例自动生成分步教学流程，每步包含临床推理依据、预期学生行为、评估标准
- **创新性**：不同于静态的PBL教学案例，系统根据病例特征动态生成个性化诊断推理教学路径，且每一步都要求学生阐明推理依据而非仅给出答案，实现"教推理过程而非教结论"
- **应用场景**：临床诊断学教学、住院医师规范化培训考核、医学执业资格考试备考

- **创新性**：将临床AI辅助决策系统的推理引擎反向用于教学，让学生观察和理解AI的完整临床决策链路，实现"用AI教人思考"的教学范式
- **应用场景**：临床治疗学教学、住院医师规范化培训、临床药师培训

- **创新性**：不同于传统题库人工命题或AI单次生成，采用"AI生成+AI审查+人工终审"三级质量保障，审查AI可自动发现并标记争议题目供教师重点关注
- **应用场景**：医学教育题库建设、执业资格考试命题、继续教育考核

- **创新性**：将AI双角色审查机制应用于教学讨论场景，提纲不仅包含引导问题还基于病例关键点自动生成预期辩论方向和分层讨论线索，实现讨论教学的结构化智能备课
