Industry Context

优质资源高度集中，基层诊疗能力缺口巨大

中国医疗机构呈典型的倒金字塔结构：顶级医院虹吸优质资源，而承担基础诊疗的基层机构数量庞大、能力有限。

复旦百强

约 100 家，仅分布 23 城，90%+ 地级市无百强医院

三甲医院

1,876 家，占医院总数不足 5%，2024 年承担 28.7 亿人次诊疗

其他医院

三乙/二级/一级等约 3.7 万家，连接顶层与基层

基层机构

约 105.5 万个，村卫生室 56.0 万 + 诊所 42.4 万，构成"第一道防线"

庞大基层数量与有限诊疗能力的反差，为医疗 AI 提供了广阔的应用空间。

Policy Tailwind

两大政策文件，指明行业方向

2025.01 发布

《国家数据基础设施建设指引》

构建"横向联通、纵向贯通"的国家级数据基础设施，未来五年带动总投资 2 万亿元。医疗要求：电子病历跨区域共享互认、多维健康数据融合、可信数据空间与隐私保护。

国卫办规划发〔2025〕30号

《"人工智能+医疗卫生"应用实施意见》

2027 建立高质量数据集、临床专病专科垂直大模型，基层智能辅助广泛应用；2030 基层基本全覆盖，二级以上医院普遍开展影像智能辅助诊断。

政策驱动医疗数据要素化与价值释放，基层 AI 医疗进入窗口期。

Policy Alignment 01

契合数据中心建设要求

国家卫健委强制标准 + 临床指南 + 专家共识三层质控，35 项指标，与"高质量数据集"要求一致。

区域 AI 服务中心统一模型、质控与数据；轻量化 Docker 部署，敏感数据县域统一出口加密，满足"可信数据空间"。

互联互通

"1 个县级牵头医院 + N 家乡镇卫生院"星形网络，对接"东数西算"网络主干道技术路线。

Current Challenges

医疗信息化六大核心痛点

制约医疗服务质量与运营效率的六大问题。

诊断编码不完整

医生凭经验编码，并发症/合并症易遗漏，影响 DRG 分组准确性

DRG 管理粗放

缺乏实时分组与盈亏分析工具，无法及时调整诊疗策略

质控工作量大

质控指标靠人工逐案筛查，效率低、覆盖范围有限

病历书写效率低

依赖键盘逐字录入，格式不规范，消耗医生大量时间

信息孤岛严重

HIS/LIS/PACS 各自独立，数据不互通，难形成完整患者画像

AI 门槛高

传统 AI 系统动辄百万投入，基层医院无力承担，技术普惠困难

Severe Consequences

痛点直接导致运营与诊疗质量下滑

医保收益流失

编码不完整导致 DRG 分组不准，医保支付未能反映实际服务成本与医疗价值。

收入持续下降

缺乏 DRG 精细化管理工具，医保付费改革下医院收入面临持续下滑。

人力消耗巨大

质控依赖人工逐案筛查，漏检率高，耗费大量人力成本。

诊疗效率低下

病历书写占用大量临床时间，直接影响诊疗服务效率。

决策依据不全

信息孤岛使医生缺乏患者全景视图，临床决策缺少完整数据支持。

数字鸿沟加剧

高 AI 投入门槛使基层被排除在技术红利之外，合规风险高企。

System Architecture

双服务器分离架构

主服务器与执行服务器职责分离，业务系统与 AI 计算高可用解耦。

主服务器

业务逻辑处理、REST API 接口、患者数据管理、任务调度，以及与医院 HIS/LIS 系统对接。

执行服务器

独立负责 AI 大模型调用引擎、Prompt 组装与管理、长耗时任务异步处理及重试与熔断机制。

性能隔离

AI 计算与日常操作分离，高负载不阻塞系统

故障隔离

执行服务异常不影响主业务

独立扩展

按负载各自水平扩展，资源利用更高效

灵活部署

支持单院独立与区域集中部署

AI Diagnostic System

AI 诊疗辅助系统

智能组装患者数据为 Prompt，调用大语言模型提供诊断建议和治疗方案参考。

核心功能

Prompt 智能组装：内置诊断分析、治疗建议、风险评估模板，支持自定义
多模型支持：DeepSeek Chat、阿里百炼等灵活切换
流式响应：实时返回生成结果
结果管理：历史分析可编辑反馈

工作流程

患者数据 → 智能组装 Prompt → 调用大模型 → 生成诊断建议 → 医生参考决策

MCC / CC Screening

并发症智能筛查

基于 12,000+ 条 MCC 字典，自动筛查严重并发症/合并症（MCC）与一般并发症/合并症（CC），提升诊断编码完整率。

智能匹配算法

编码精确匹配 + 名称相似度匹配（Levenshtein），双重保障筛查准确性

自动排除规则

内置医学逻辑排除规则引擎，过滤误匹配项，避免假阳性

分组优先级排序

按来源诊断智能分组，MCC 优先于 CC 呈现，符合临床诊断逻辑

编码完整率提升

直接提升诊断编码完整率，为 DRG 分组提供支撑
