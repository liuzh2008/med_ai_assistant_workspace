# 中国医院分布情况分析

**数据来源**：《2024年我国卫生健康事业发展统计公报》（国家卫健委，2025年12月发布）、复旦版《2023年度中国医院综合排行榜》

---

## 一、总体概览

截至2024年末，全国共有：

| 类别 | 数量 |
|------|------|
| 医院总数 | 约38,710个 |
| 基层医疗卫生机构 | 约104万个 |
| 全国医疗卫生机构总数 | 约109.35万个 |

**金字塔结构**：顶级医院不到100家，三甲医院1,876家，而三乙及以下基层医疗机构超过100万家——这是一个极度向上集中的倒金字塔结构。

## 三、第二梯队：三甲医院（1,876家）

**评定标准**：经省级卫生行政部门评审通过的三级甲等医院

| 指标 | 数据 |
|------|------|
| 三级医院总数 | 4,111个 |
| 其中：三甲医院 | **1,876个** |
| 三乙及其他三级 | 2,235个 |
| 占全国医院比例 | 4.8% |
| 2024年诊疗量 | **28.7亿人次**（占全国总诊疗量的最大份额） |

### 关键特征

- 三甲医院以不到5%的机构数量，承担了全国最大比例的诊疗量，**虹吸效应极为严重**
- 主要分布在地级市以上城市，县域覆盖不足
- 但近年有1,309家县医院达到三级医院能力标准，趋势向好

## 四、第三梯队：三乙及以下基层医院

这一层级是数量最庞大的群体，包括多个子类别：

### 按医院等级划分

| 类别 | 数量 | 说明 |
|------|------|------|
| **二级医院** | 12,294个 | 多为县区级医院，基层诊疗主力 |
| **一级医院** | 13,287个 | 社区医院、小型专科医院 |
| **未定级医院** | ~9,018个 | 新建或规模较小的医院 |

### 基层医疗卫生机构细分

| 机构类型 | 数量 |
|---------|------|
| 乡镇卫生院 | 3.33万个 |
| 村卫生室 | 57.04万个 |
| 社区卫生服务中心 | 1.02万个 |
| 社区卫生服务站 | 2.71万个 |
| 门诊部及诊所 | 40多万个 |
| **合计** | **约104万个** |

### 基层关键数据

- 基层卫生队伍：**525.7万人**（占全国卫生人员的三分之一）
- 基层诊疗量占比：**50%以上**
- 超过90%的居民可在15分钟内就近就医
- 乡镇卫生院/社区卫生服务中心平均配备药品约**300种**
- 基层全科医生：**63.87万人**，每万人口4.54人
- 超90%的乡镇卫生院和社区卫生服务中心达到基本服务能力标准

## 六、核心洞察

### 1. 倒金字塔结构带来的问题

- 顶级100家医院 + 三甲1,876家仅占医院总数的约5%，却吸引了绝大部分优质资源（人才、设备、资金）
- 12,294家二级医院和104万个基层机构是真正服务基层群众的主力，但**诊疗能力与三甲差距巨大**
- 这是国家大力推动"基层诊疗AI全覆盖"政策的根本原因

### 2. 基层医疗的"能力鸿沟"

- 基层有机构（104万）、有人（525.7万人）、有患者（50%以上诊疗量）
- 但缺乏的是**高水平诊断能力**和**标准化治疗方案**
- 这正是AI辅助诊疗系统的核心应用场景——用技术填补能力缺口

### 3. 本系统的市场空间

- 1,876家三甲医院 → 主要面向本地大模型方案
- **12,294家二级 + 13,287家一级医院 + 104万基层机构** → 本系统轻量化部署方案的天然市场
- 这是一个**百万级的潜在终端市场**，完全契合国家2030年基层AI全覆盖目标

### 4. 地理集中的战略意义

- 百强医院48%集中在北上广，意味着**全国绝大多数地区没有顶级医疗资源**
- 通过AI将顶级诊疗能力"云端化分发"到基层，是缩小地区医疗差距的最可行路径
