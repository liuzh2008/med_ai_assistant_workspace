# 诊疗计划表显示美化方案

## 现状分析

当前 `AIResults.vue` 中通过 `marked.parse()` 将 Markdown 表格渲染为 HTML `<table>`，但 **没有任何表格 CSS 样式**（第905-970行只有 thinking 折叠块样式）。表格使用浏览器默认样式显示，无边框、无内边距、无视觉层次。

**涉及文件**：`med_ai_assistant_1.0_bs_vue/src/components/ai/AIResults.vue`

---

## 美化目标

基于用户提供的诊疗计划表结构（4列：项目类型 / 项目描述 / 注意事项 / 重要程度），实现以下效果：

1. **基础表格样式** - 边框、内边距、表头背景、斑马纹
2. **重要程度色标** - "危急"红色、"重要"橙色、"一般"灰色标签
3. **分类行高亮** - "护理及监测"、"药物"等分类标题行以醒目样式突出
4. **注意事项富文本** - 支持 `<br>` 换行、编号列表在单元格内的良好排版
5. **响应式处理** - 表格过宽时支持水平滚动

---

## Task 1：添加基础表格 CSS 样式

**范围**：`AIResults.vue` 的 `<style scoped>` 部分，在 thinking 样式后追加表格样式

添加以下 `:deep` 样式规则：

```css
/* 表格容器 - 支持水平滚动 */
.result-content :deep(table) {
  border-collapse: collapse;
  width: 100%;
  margin: 12px 0;
  border: 1px solid #dcdfe6;
  font-size: 12px;
  table-layout: fixed;       /* 固定列宽，防止内容撑开 */
}

/* 表头 */
.result-content :deep(th) {
  background-color: #f0f5ff;  /* 浅蓝色表头 */
  font-weight: 600;
  color: #303133;
  border: 1px solid #dcdfe6;
  padding: 10px 12px;
  text-align: center;
  white-space: nowrap;
}

/* 单元格 */
.result-content :deep(td) {
  border: 1px solid #e4e7ed;
  padding: 8px 12px;
  vertical-align: top;
  line-height: 1.6;
  word-break: break-word;
}

/* 斑马纹 */
.result-content :deep(tr:nth-child(even)) {
  background-color: #fafbfc;
}

/* 悬停高亮 */
.result-content :deep(tbody tr:hover) {
  background-color: #f0f7ff;
}
```

**列宽分配建议**（通过 `table-layout: fixed` + `th` 宽度控制）：
- 项目类型：~12%
- 项目描述：~33%
- 注意事项：~40%
- 重要程度：~15%

## Task 2：在 parseMarkdown 中添加表格后处理逻辑

**范围**：`AIResults.vue` 的 `parseMarkdown()` 方法（第408-448行）

在 `marked.parse()` 之后、`DOMPurify.sanitize()` 之前，插入表格内容后处理：

### 2.1 重要程度色标

扫描表格单元格内容，为"危急"、"重要"、"一般"文本包裹带样式的 `<span>` 标签：

```javascript
// 重要程度色标映射
html = html.replace(/<td([^>]*)>\s*(危急)\s*<\/td>/g,
  '<td$1><span class="severity-badge severity-critical">$2</span></td>')
html = html.replace(/<td([^>]*)>\s*(重要)\s*<\/td>/g,
  '<td$1><span class="severity-badge severity-important">$2</span></td>')
html = html.replace(/<td([^>]*)>\s*(一般)\s*<\/td>/g,
  '<td$1><span class="severity-badge severity-normal">$2</span></td>')
```

### 2.2 分类行高亮

检测"项目类型"列有内容但其他列为空的行（如"护理及监测"、"药物"等分类标题行），为其添加 CSS 类：

```javascript
// 检测分类标题行：第一个td有加粗内容，后续td为空
html = html.replace(
  /<tr>\s*<td([^>]*)>\s*(<strong>.*?<\/strong>)\s*<\/td>\s*(<td[^>]*>\s*<\/td>\s*){2,}<td[^>]*>\s*<\/td>\s*<\/tr>/g,
  '<tr class="category-row"><td$1>$2</td><td></td><td></td><td></td></tr>'
)
```

## Task 4：DOMPurify 白名单更新

**范围**：`AIResults.vue` 的 `parseMarkdown()` 方法末尾的 `DOMPurify.sanitize()` 调用

确保新增的 class 和 span 标签不被过滤：

```javascript
return DOMPurify.sanitize(html, {
  ADD_TAGS: ['div', 'span'],
  ADD_ATTR: ['onclick', 'id', 'class', 'style']
})
```

当前配置已包含 `span` 和 `class`，**无需修改**。
