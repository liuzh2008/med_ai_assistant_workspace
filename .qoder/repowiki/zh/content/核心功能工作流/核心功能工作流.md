## 生成入院记录总结工作流

该工作流实现了从用户触发到AI生成并展示入院记录总结的完整过程，核心涉及`AIView.vue`、`promptUtils.js`和`AIResults.vue`三个组件。

### 触发与检查机制

工作流始于`AIView.vue`组件的`mounted`生命周期钩子，当用户进入AI视图时，会自动调用`checkAdmissionRecords`方法。该方法首先检查当前患者是否存在“入院记录总结”类型的Prompt记录。

```mermaid
sequenceDiagram
participant AIView as AIView.vue
participant API as ai.js
participant PromptUtils as promptUtils.js
AIView->>API : getPrompts(patientId, '入院记录总结')
API-->>AIView : 返回Prompt记录列表
alt 无总结记录
AIView->>API : getAdmissionRecords(patientId)
API-->>AIView : 返回入院记录
alt 有入院记录
AIView->>用户 : 显示确认对话框
用户-->>AIView : 确认生成
AIView->>AIView : 调用generateAdmissionSummary()
end
end
```

### 数据协调与模板执行

当用户确认生成总结时，`AIView.vue`调用`promptUtils.js`中的`handlePromptExecution`函数。该函数是整个流程的核心协调器，负责并行获取患者数据和Prompt模板内容。

```mermaid
flowchart TD
A[开始] --> B{参数验证}
B --> |失败| C[抛出错误]
B --> |成功| D[获取患者数据]
B --> |成功| E[获取Prompt模板]
D --> F[处理患者数据格式]
E --> G{模板内容为空?}
G --> |是| H[返回失败]
G --> |否| I[合并数据]
I --> J[附加信息]
J --> K[验证用户登录]
K --> L[调用addPrompt保存记录]
L --> M{保存成功?}
M --> |是| N[返回成功]
M --> |否| O[返回失败]
```

### 结果展示

当AI处理完成后，结果会通过`AIResults.vue`组件展示给用户。该组件通过Vuex store监听`result`状态的变化，并使用`marked`库将Markdown格式的AI回复渲染为HTML。

```mermaid
sequenceDiagram
participant AIResults as AIResults.vue
participant Store as Vuex Store
participant Markdown as marked
Store->>AIResults : result状态更新
AIResults->>Markdown : parse(result.content)
Markdown-->>AIResults : 返回HTML
AIResults->>DOM : v-html渲染结果
```

## AI对话工作流

该工作流实现了与AI模型的实时对话功能，核心特点是消息的流式接收与显示，主要由`AIResponse.vue`和`aiService.js`实现。

### 流式响应处理

`AIResponse.vue`组件在用户发送消息后，调用`getAIResponseWithParams`函数。该函数内部使用`aiService.js`的`getAIResponseStream`方法，通过fetch API的流式读取能力，逐块接收AI的响应。

```mermaid
sequenceDiagram
participant User as 用户
participant AIResponse as AIResponse.vue
participant AIService as aiService.js
participant Server as AI服务器
User->>AIResponse : 输入消息并点击发送
AIResponse->>AIService : getAIResponseStream()
AIService->>Server : POST /api/ai/response (stream : true)
loop 流式接收
Server->>AIService : 发送数据块 (NDJSON)
AIService->>AIService : 解码并解析JSON
AIService->>AIResponse : onData(data)
AIResponse->>AIResponse : 累积内容并更新UI
AIResponse->>DOM : 实时显示部分响应
end
AIService->>AIResponse : onData(null, true, null)
AIResponse->>User : 显示完整响应
```

## 添加诊断功能

该功能实现了将AI输出的文本诊断转化为结构化诊断条目的过程，涉及`AIResults.vue`、`DiagnosisEditDialog.vue`和`patient.js` store模块。

### 文本提取与结构化

在`AIResults.vue`中，当用户点击“显示列表”按钮时，`showDiagnosisDialog`方法会解析AI回复内容，通过正则表达式提取出诊断名称。

```mermaid
flowchart TD
A[用户点击显示列表] --> B[showDiagnosisDialog]
B --> C{prompt.title包含'诊断分析'?}
C --> |是| D[使用正则表达式提取诊断]
D --> E[/#### 诊断名称: (.+?)(?:\n|$)/]
E --> F[去重并格式化为对象数组]
F --> G[存入aiDiagnosis状态]
C --> |否| H[aiDiagnosis为空]
G --> I[显示DiagnosisEditDialog]
```

### 诊断条目管理

`DiagnosisEditDialog.vue`组件提供了一个双表界面，左侧显示AI提取的诊断，右侧显示患者当前的诊断。用户可以选择AI诊断并点击“插入”按钮，将其添加到患者诊断列表中。

```mermaid
sequenceDiagram
participant Dialog as DiagnosisEditDialog.vue
participant Store as Vuex Store
participant PatientStore as patient.js
Dialog->>用户 : 显示AI诊断和当前诊断
用户->>Dialog : 选择AI诊断并点击插入
Dialog->>Store : dispatch('patient/addDiagnosis')
Store->>PatientStore : addDiagnosis action
PatientStore->>API : 调用添加诊断API
API-->>PatientStore : 返回成功
PatientStore-->>Store : 提交mutation
Store-->>Dialog : 刷新诊断列表
```
