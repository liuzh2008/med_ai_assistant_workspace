# 专利技术交底书去 AI 痕迹

## 背景

2025-2026 年起，国家知识产权局 (CNIPA) 和各地知识产权保护中心严查 AI 直接生成的专利申请文件。南京中心明确禁止预审案件中使用 AI 直接生成内容，CNIPA 将 AI 生成申请定性为不诚信申请行为。

主流 AI 文本检测器依赖三个指标：
- **困惑度 (Perplexity)**：AI 文本词选择过于"安全"可预测，人类文本波动大
- **突发性 (Burstiness)**：AI 文本句子间困惑度变化近乎为零（节奏均匀），人类文本有显著波动
- **文体特征 (Stylometric)**：AI 过度使用特定词性、标点模式单一

注意：专利文本因其法定格式约束天然就是低困惑度文本，因此降低困惑度效果有限——重点应放在**消除非格式约束导致的 AI 特征**（结构模板、特定词汇、句式雷同）。

## 识别 AI 痕迹

### 结构模板（优先级最高）

- `X大核心缺陷` + ①~⑥ 编号列表
- `问题一`~`问题N`，每条以 `需建立/需设计/需实现/需输出` 开头
- `效果一`~`效果N`，每条以 `通过…实现…` 或 `实现…` 开头
- `有益效果` 中有 5~8 条且句式高度雷同

### AI 高频词汇

| 类别 | 需替换的词 |
|------|-----------|
| 修饰前缀 | `核心创新` `核心指令` `核心约束` `核心原则` `核心字段` `核心编排` `核心特征` |
| 修饰词 | `精确定位` `系统性偏见/偏差` `最大化` |
| 动词 | `确保`（过量使用时） |
| 句式模板 | `通过…实现…` `不仅…更…` `如图所示` `具体包括以下步骤` |

### 其他特征

- Emoji 图标（在段落文字中，Mermaid 节点标签内除外）
- 中文破折号 `——` 过量使用
- 英文缩写首次出现必加全称括号（AI 的"过度解释"习惯）
- 段落长度高度均匀、缺乏长短交替

## 改造规则

### 规则一：打破数字模板

**背景技术**：将 `X大核心缺陷` 改为 `几个突出问题`，表格列头 `缺陷` 改为 `问题`，去掉 ①~⑥ 序号。

**技术问题**：将编号的 `问题一`~`问题N` 按主题合并为 2-3 个自然段落，每段覆盖 2-3 个相关子问题。段落之间用不同的引导句（如"X面临的首要难题是…""Y构成了另一个关键需求""在基础设施层面…"）。

**有益效果**：将 `效果一`~`效果N` 合并精简为 4-5 条。若原文有 8 条，可合并为 5 条（如容错降级+SSE推送可并入 Prompt 引擎一条，跨场景复用独立一条）。

### 规则二：有益效果句式完全多样化

严禁所有条目以同一句式开头。混合使用五种句式：

| 句式 | 示例 |
|------|------|
| 结果前置 | `双角色交叉验证消除了单模型自我审查的盲区。` |
| 策略描述 | `优化AI采用定向修正而非完全重写的策略，保住了…` |
| 机制描述 | `审查标准根据目标学员层级自适应调整。` |
| 工具主语 | `数据库驱动的Prompt模板引擎使模板修改不再依赖…` |
| 属性陈述 | `该双角色架构具备跨场景的复用能力。` |

每条展开为 4-6 句的完整段落，加入具体数据或案例，而非 1-2 句概述。

### 规则三：词汇替换

全文扫描并替换。优先改技术描述章节（S101-S10X），权利要求仅做最小替换以保持保护范围不变。

| 替换前 | 替换后 | 注意 |
|--------|--------|------|
| `核心创新` `核心指令` `核心约束` `核心原则` `核心字段` | 去掉"核心"或改为 `创新点` `主要指令` `基本处理原则` `主要字段` | 表格中的"核心特征"可保留 |
| `精确定位` | `段落位置` `位置标注` `标注教案段落位置` | 权利要求中用 `标注…位置` |
| `系统性偏差` `系统性偏见` | `固有偏差` `固有偏见` | |
| `确保` | `保障` `保证` `使得` 或重构句式 | 每 500 字不超过 1 次 |
| `最大化` | `充分保留` `尽可能` | |

### 规则四：保留真实内容不动

- **Mermaid 图表**：若为根据实际代码生成的，全部保留不修改
- **权利要求**：仅做最小词汇替换，不改变保护范围
- **技术步骤** (S101-S10X)：保留技术精确性，只替换标记词汇
- **引用文献、发明人信息、附件清单**：不做改动

## 工作流程

1. **通读识别**：用 Grep 扫描 `核心|确保|精确定位|系统性|最大化|问题一|效果一|六大|X大`，记录所有命中位置
2. **背景技术**：去掉数字标签和序号，表格列头改为中性词
3. **技术问题**：按主题合并编号问题为自然段落，两个主题方向：（a）核心技术机制（b）可解释性与衔接
4. **有益效果**：合并精简为 4-5 条，重写每条的首句使其句式各异，展开为完整段落
5. **全文词汇**：逐一替换 AI 高频词
6. **验证**：确认 Mermaid 图表完整、权利要求一致、无信息丢失、无残留 `问题一/效果一` 等编号标签
