# Lookup Unfinished Features

## Instructions

当需要了解项目中未完成的功能或待办迭代任务时：

1. 读取项目迭代文档中的未完成功能清单
2. 按优先级/分类整理未完成的功能列表
3. 将结果返回给用户

## 文档路径

未完成功能文档位于：
- `med_ai_assistant_1.0_bs_backend/doc/迭代/未完成功能.md`

该文档包含以下分类内容：
- **待处理** — 当前待处理的迭代任务
- **待开发功能** — 已完成方案设计、待开发的新功能

## 文档结构说明

文档中的每个任务通常包含：
- 复选框状态（`[ ]` 未完成 / `[x]` 已完成）
- 优先级标注（高/中/低）
- 任务背景说明
- 改造要点和涉及文件
- 参考链接（如有）
- 方案文档路径（如有）
