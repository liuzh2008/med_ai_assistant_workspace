# 手术期（Preop & Postop）

## 适用场景 / 触发条件

- 择期手术患者进入围手术期，需完成术前评估、术前讨论、术前小结（流程步骤 #18-#25）；
- 术后需在 24h 内写手术记录、术后首次病程，并连续 3 天记录术后每日病程；
- 医生要求"写术前讨论""把术前小结一起写了""手术记录/术后病程"。

## 执行步骤（编号）

1. **患者锚定与阶段确认**：调用 `medai_patient_list_by_department` / `medai_patient_basic_info` 确认患者，`medai_patient_flow_status` 确认处于手术期（有手术计划/已手术）。
2. **术前评估**：
   - 诊断与既往：`medai_patient_diagnoses`、`medai_medical_records`；
   - 术前检查完整性：`medai_lab_results` / `medai_exam_results` 核对术前检查是否齐备（血常规、凝血、肝肾功能、心电图、影像等，按手术类型核对**检查缺项**）；
   - 缺项清单明确列出，提示医生补充，不跳过。
3. **术前讨论（DB 模板约束）**：调用 `medai_record_generate`（模板：术前讨论记录，**必须使用 DB 模板约束**）生成——病情分析、手术指征、风险评估、讨论结论；同步等待快速类可走 `medai_record_generate_sync`。
4. **术前小结（与术前讨论一链）**：调用 `medai_record_generate`（模板：术前小结）生成——病情摘要、术前诊断、手术计划；**复用术前讨论数据**一链产出，避免重复录入。
5. **术前医嘱核对**：调用 `medai_patient_orders` 核对术前医嘱（禁食、备皮、术前用药、手术通知）；缺项给建议，**需医生审批**，不直接写回。
6. **手术记录（术后 24h）**：医生口述术中要点（手术方式、术中所见、出血量、麻醉方式等）→ 调用 `medai_record_generate`（模板：手术记录）结构化生成草稿；提醒 24h 时限。
7. **术后首次病程（术后即时）**：调用 `medai_record_generate`（模板：病程记录）生成——术后情况、注意事项（引流、生命体征观察）。
8. **术后每日病程 + 频次提醒**：术后连续 3 天每日记录（恢复评估、换药、拆线），引用 `medai_due_documents`（未来工具）核对术后病程频次与到期项。

## 文书格式要点

- **术前讨论记录**：讨论时间/地点/参加人员 → 病情及诊疗经过 → 术前诊断 → 手术指征 → 手术方案 → 风险评估与防范措施 → 讨论结论；**结构与字段受 DB 模板约束，不得自行增删**。
- **术前小结**：病情摘要 → 术前诊断 → 手术名称/方式 → 手术日期 → 麻醉方式 → 手术者 → 备血/过敏史。
- **手术记录**：手术日期时间 → 术前/术中/术后诊断 → 手术名称 → 手术者/助手/麻醉 → 手术经过（切口、探查、处理、缝合、引流）→ 术中出血输血 → 术中用药 → 标本送检。
- **术后病程**：术后情况（生命体征、引流、疼痛、伤口）→ 注意事项 → 换药/拆线计划。

## 审核与保存要求

- 术前讨论/小结/手术记录/术后病程均为 **AI 草稿**，医生审核确认后生效；
- 正式病历落库走审批（草稿→审核→审批→diff 留痕），agent 不直接写正式病历；
- 手术知情同意（签字）是**人的行为**（不介入），agent 只可提醒待办，不代签、不生成同意书内容替代签字。

## 注意事项（脱敏/患者锚定）

- 术前讨论必须按 DB 模板约束生成，禁止偏离模板结构；
- 术中信息以医生口述为准，agent 不得臆造手术细节；
- 术前检查缺项清单要完整呈现，宁可多提示不漏项；
- 对话与卡片中不出现患者明文 PII（姓名/身份证号等）。
