# 会诊（Consultation）

## 适用场景 / 触发条件

- 患者病情需要其他科室会诊：**请会诊**（申请方）或**会诊意见**（受邀方）（流程步骤 #15）；
- 常规会诊 48h 内完成、急会诊 10min 到场——时限提醒；
- 医生要求"写个请会诊记录""会诊意见整理一下"。

## 执行步骤（编号）

1. **患者锚定**：调用 `medai_patient_list_by_department` / `medai_patient_basic_info` 确认患者，`medai_patient_diagnoses` 获取诊断，`medai_patient_flow_status` 看当前阶段。
2. **会诊背景取数**：调用 `medai_medical_records`（近次病程）、`medai_lab_results` / `medai_exam_results`（相关检查检验）汇总病情摘要——供会诊科室快速了解。
3. **生成请会诊记录**：调用 `medai_record_generate`（模板：请会诊记录，**additionalInfo 补充会诊目的与拟解决问题**）生成草稿——患者病情摘要、会诊目的、拟请科室、期望时限；快速类可走 `medai_record_generate_sync`。
4. **时限提醒**：引用 `medai_due_documents`（未来工具）核对会诊时限（常规 48h / 急会诊 10min 到场），超时未完成时提醒医生跟进。
5. **会诊意见整理**（受邀方场景）：按会诊意见要点（诊断意见、处理建议、随访要求）调用 `medai_record_generate`（模板：会诊意见记录）生成草稿，医生确认后归档。
6. **闭环核对**：会诊申请→会诊意见→病程记录记录会诊结论，缺环时提醒补记。

## 文书格式要点

- **请会诊记录**：患者基本信息（脱敏）→ 病情摘要 → 会诊目的（拟解决的具体问题）→ 拟请科室 → 会诊类别（普通/急）→ 申请医师/时间；
- **会诊意见记录**：会诊科室/医师 → 会诊时间 → 会诊意见（诊断/处理建议）→ 会诊医师签名；
- 急会诊必须标注"急"，时间精确到分钟。

## 审核与保存要求

- 请会诊记录/会诊意见为 AI 草稿，**医生审核后**生效，落库走审批通道；
- 会诊意见以受邀医师口述为准，agent 只做结构化整理，不代拟医疗意见；
- 会诊流程（申请→响应→意见→病程记录）缺环时明确提醒。

## 注意事项（脱敏/患者锚定）

- additionalInfo 中补充的会诊目的须经脱敏（不写患者姓名/身份证号等 PII）；
- 会诊意见属于医疗决策，agent 仅整理呈现，不生成治疗建议；
- 急会诊时限敏感，从接报时刻起算，提醒务必醒目。
