# 危急值闭环（Critical Value）

## 适用场景 / 触发条件

- 检验/检查出现危急值，需**接报→处理→记录**闭环（流程步骤 #14/#34）；
- 医生询问"有没有危急值""这个危急值处理了吗/记录了吗"；
- 危急值处理记录缺失时提醒补记（闭环跟踪）。

## 执行步骤（编号）

1. **危急值查看**：调用 `medai_lab_results` / `medai_exam_results` 查看最新危急值回报（项目、数值、参考范围、回报时间）；调用 `medai_patient_basic_info` 确认患者与床号，`medai_patient_diagnoses` 了解诊断背景。
2. **评估与处理**：向医生呈现危急值并询问处理意见（复查、用药、会诊、转科等）；agent 只整理医生口述的处理措施，**不做医疗决策**；必要时联动 consultation（会诊）剧本。
3. **生成危急值处理记录**：调用 `medai_record_generate`（模板：危急值处理记录/病程记录）生成草稿——回报项目与数值、接报时间、处理措施、处理时间、医嘱调整；快速类可走 `medai_record_generate_sync`。
4. **闭环核对**：引用 `medai_due_documents`（未来工具）核对该患者危急值处理记录是否已写（闭环）；未闭环则明确提醒医生补记，并列入待办。
5. **记录审核**：草稿经医生审核后保存；落库走审批通道。

## 文书格式要点

- **危急值处理记录**：报告时间/项目/数值（含单位与参考范围）→ 报告科室 → 接报医生 → 临床评估 → 处理措施（具体到医嘱/处置）→ 处理时间 → 复查结果（如有）；
- 时间线必须完整：**接报 → 评估 → 处理 → 记录**四个节点时间齐全；
- 数值保留原始单位，不换算不省略。

## 审核与保存要求

- 危急值处理记录为 AI 草稿，**医生审核后**生效，正式病历落库走审批；
- 危急值闭环的"处理"动作必须由医生完成，agent 只协助记录与提醒；
- 已闭环与未闭环状态清晰标注，未闭环持续提醒直至闭环。

## 注意事项（脱敏/患者锚定）

- 危急值涉及具体数值与患者信息，展示用脱敏标签，明文报告只走报告单卡片；
- 处理措施必须以医生口述为准，agent 禁止擅自给出处理方案或"代为处理"；
- 超时未处理/未记录时如实提醒，不掩盖、不编造处理记录。
