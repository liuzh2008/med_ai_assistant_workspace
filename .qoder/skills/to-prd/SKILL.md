# 将对话合成 PRD

## 概述

基于当前对话中已讨论的需求、功能点和技术方案，自动合成结构化的 PRD 文档，并提交为 GitHub Issue。

## 执行步骤

### 步骤一：信息提取

从当前对话中提取以下关键信息：
1. **项目/模块名称**：正在讨论的是什么
2. **业务背景**：为什么要做这个功能
3. **功能需求**：具体需要实现什么
4. **技术方案**：拟采用的技术路线
5. **约束条件**：性能、安全、兼容性等要求
6. **验收标准**：如何验证功能完成

### 步骤二：生成 PRD

按以下结构生成 PRD 文档：

```markdown
# PRD：[项目/模块名称]

## 1. 背景与目标
[业务背景和动机]

## 2. 功能需求
### 2.1 [功能1]
[描述]

### 2.2 [功能2]
[描述]

## 3. 技术方案
[技术路线概述]

## 4. 约束条件
- 性能要求：[...]
- 安全要求：[...]
- 兼容性：[...]

## 5. 验收标准
- [ ] [验收标准1]
- [ ] [验收标准2]

## 6. 附录
[相关链接、参考资料]
```

### 步骤三：提交 Issue

将生成的 PRD 提交为 GitHub Issue：
1. Issue 标题：`PRD: [模块名称]`
2. Issue 标签：`prd`, `documentation`
3. Body 内容：完整的 PRD 文档
4. 通知相关协作者（如有）

## 输出

```markdown
## PRD Issue
- **标题**：PRD: [模块名称]
- **链接**：[Issue URL]
- **摘要**：[一句话描述]
```
