# 晨交班 / 交接班（Handover）

## 适用场景 / 触发条件

- 每日晨交班（流程步骤 #9）：夜班交班、危重患者交接，信息易口头遗漏；
- 值班/交接班场景（#33）：危重患者接班、待办事项传递；
- 医生要求"把交班要点整理一下""晨交班记录"。

## 执行步骤（编号）

1. **患者清单聚合**：调用 `medai_patient_list_by_department` 拉取本科室在院患者清单，`medai_patient_flow_status` 获取患者阶段（重点标注危重/手术/新入院患者）。
2. **逐患者要点取数**（按危重程度排序）：
   - 基本信息与诊断：`medai_patient_basic_info`、`medai_patient_diagnoses`；
   - 夜间病情变化：`medai_medical_records`（近次病程/值班记录）；
   - 新回报的检验/检查：`medai_lab_results` / `medai_exam_results`（重点危急值，见 critical-value 剧本）；
   - 医嘱变动：`medai_patient_orders`。
3. **要点聚合**：按"患者（床号+脱敏标签）→ 病情变化 → 检查回报 → 治疗调整 → 待办事项"结构汇总交班要点；危重患者置顶并标注。
4. **生成交接班记录**：调用 `medai_record_generate`（模板：交接班记录/晨交班要点）生成草稿——快速类可走 `medai_record_generate_sync`；同步提醒医生核对口头交接中易漏的检查回报与待办。
5. **待办核对**：引用 `medai_due_documents`（未来工具）核对接班后到期文书/待办（会诊、手术、危急值处理等），纳入交接清单。

## 文书格式要点

- **交接班记录**：交班日期/班次 → 在院患者总数与危重数 → 逐患者条目（床号/脱敏姓名、诊断、夜间情况、检查回报、医嘱变动、待办）→ 交班人/接班人签名；
- 危重患者条目放最前，标注"危重"；新入院/术后患者单独标注；
- 要点**精炼可执行**（每患者 2-5 条），不堆砌病程全文。

## 审核与保存要求

- 交接班记录为 AI 草稿，**交班医生审核确认**后生效；
- 口头交接中的关键信息（尤其危急值与待办）必须落到书面记录，防断层；
- 落库走审批通道，agent 不直接写正式记录。

## 注意事项（脱敏/患者锚定）

- 聚合前确认科室与患者范围，不跨科室拉取；
- 交班展示用脱敏 patientLabel，不出现患者明文姓名/身份证号；
- 危重判定以现有数据（诊断/医嘱/检查）为依据，agent 不做超范围临床判断；
- 交接班记录只汇总事实，不添加推断性结论。
