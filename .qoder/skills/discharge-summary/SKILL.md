# 出院（Discharge Summary）

## 适用场景 / 触发条件

- 患者出院当日或出院后 24h 内，需写**出院小结**（全病程信息汇总，最耗时的文书）；
- 出院评估（出院标准核对）、出院医嘱/带药清单、病案首页与 DRG 编码核对；
- 医生要求"把出院小结写了""办出院"。

## 执行步骤（编号）

1. **患者锚定与出院确认**：调用 `medai_patient_list_by_department` / `medai_patient_basic_info` 确认患者，`medai_patient_flow_status` 确认处于出院期（已出院/待出院）。
2. **出院评估（标准核对）**：调用 `medai_patient_basic_info`、`medai_patient_diagnoses` 与 `medai_lab_results` / `medai_exam_results` 汇总病情，按病种出院标准逐项核对（症状控制、生命体征平稳、可居家管理等），向医生明示评估结论，**标准以医生判定为准**。
3. **出院医嘱/带药清单**：调用 `medai_patient_orders` 查询医嘱，按诊断给出出院带药与随访建议清单（**需医生审批**），不直接写回。
4. **生成出院小结（24h）**：调用 `medai_record_generate`（模板：出院小结）生成草稿——入院情况、诊疗经过、出院诊断、出院医嘱、随访建议；快速类可走 `medai_record_generate_sync`（草稿卡片呈现明文，agent 只拿脱敏摘要）。
5. **病案首页/DRG 辅助核对**：调用 `medai_diagnosis_analyze` 辅助核对主要诊断/手术编码与 DRG 分组一致性（费用字段在计费系统，超出本系统数据范围时提示医生核对），必要时 `medai_diagnosis_review` 复核诊断顺序。
6. **健康宣教/随访**：按出院诊断整理宣教要点与随访计划（饮食/活动/复诊/用药），供医生采用。
7. **质控归档核对**：出院小结 24h 时限提醒；引用 `medai_due_documents`（未来工具）核对归档前文书缺项/超时。

## 文书格式要点

- **出院小结**：入院日期/出院日期 → 入院情况（主诉+现病史摘要）→ 入院诊断 → 诊疗经过（重要检查、治疗、手术）→ 出院诊断 → 出院情况（症状体征）→ 出院医嘱（带药/饮食/活动/复诊）→ 医师签名。
- **病案首页核对**：主要诊断选择（本次住院治疗的核心疾病）、其他诊断、手术操作编码、入出院时间、费用类别——编码错误直接影响 DRG 分组与医保，务必谨慎。
- 出院小结覆盖全病程，信息与入院记录/病程/手术记录保持一致。

## 审核与保存要求

- 出院小结为 **AI 草稿**，医生审核修改后生效，正式病历落库走审批（diff 留痕）；
- 出院带药清单仅建议，处方以医生开具为准；
- 病案首页编码最终由医生/病案室确认，agent 只做辅助核对提示。

## 注意事项（脱敏/患者锚定）

- 出院小结是"全病程总结"，生成前确认已取全病程关键节点（入院/手术/关键检查/出院诊断）；
- 不出现患者明文 PII；宣教与随访内容基于诊断模板，不做超范围医疗建议；
- DRG 相关字段缺失时如实说明数据边界，不编造费用数据。
