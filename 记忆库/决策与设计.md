### 2026-08-13 建立项目自动长期记忆体系
- **决策**：用「AGENTS.md 强制协议 + memory-manager 技能 + 记忆库/ 文件库」三件套实现自动记忆，替代人工维护。
- **机制**：
  - 根 `AGENTS.md`（DSH 原生自动注入）强制每会话执行记忆协议；
  - `memory-manager` 技能（`.dsh/skills` → Junction → `.qoder/skills`）定义写入规范；
  - `记忆库/` 按主题分文件（决策/踩坑/环境/命令/会话），随 `.qoder/` 一起被 Git 跟踪。
- **原因**：DSH 无内建会话结束自动归档钩子；AGENTS.md 与技能目录是仅有的两个每会话自动注入点，组合后即可让 agent 自主沉淀，无需用户手动要求。
- **关联**：AGENTS.md、`.qoder/skills/memory-manager/SKILL.md`、`记忆库/索引.md`
