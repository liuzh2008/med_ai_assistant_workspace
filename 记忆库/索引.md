# 项目长期记忆库（自动沉淀）

> 本记忆库由 agent 在每个会话中**自动维护**，无需人工干预。
> 规则：每当出现关键信息（决策、踩坑、配置变更、新命令、架构调整），agent 必须立即写入对应文件，并在本索引登记。

## 文件结构

| 文件 | 记录内容 |
|---|---|
| `决策与设计.md` | 架构决策、技术选型、设计权衡（ADR 风格） |
| `踩坑与教训.md` | 已解决的问题、根因、修复方法，避免重复踩坑 |
| `环境与配置.md` | 服务器、端口、账号、SSH、环境变量、构建部署配置事实 |
| `命令与流程.md` | 常用命令、操作流程、脚本用法 |
| `会话记忆.md` | 每次会话的关键产出速记（自动追加，可被整理归入上表） |

## 维护规则（agent 每会话必须执行）

1. **会话开始时**：读取本索引 + 相关主题文件，恢复项目记忆上下文。
2. **会话中**：识别到关键信息时，立即追加到对应文件（按 `### YYYY-MM-DD 标题` 格式），并更新本索引的登记行（若有新条目）。
3. **会话结束时**：把本次会话尚未落盘的产出速记写入 `会话记忆.md`（按日期分区）。
4. **质量要求**：条目需包含"结论 + 关键细节（路径/命令/原因）"，可执行、可复现；已有条目则更新而非重复。
5. **不写入**：闲聊、临时性内容、可随时从代码/文档推导的内容。

## 检索方式

- 先看本索引定位主题文件，再 read 对应文件。
- 不确定是否已有记录时，用 grep 在本目录检索关键词。
