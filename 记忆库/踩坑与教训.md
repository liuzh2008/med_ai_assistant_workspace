### 2026-08-21 医疗流程通用编排 TDD 实施九连坑（Java record/Mockito/YAML 体例）

### 2026-08-19 verify-mcp-gateway.sh 两个既有 bug（AUTH_HDR 静态构造 + isError 宽匹配）——全场景 MCP_AUTH_INVALID_JWT 的排查链
- 现象：jwt-enabled=true 后（N4 双因子），verify-mcp-gateway.sh 几乎全场景返回 `{"code":"MCP_AUTH_INVALID_JWT","message":"Unauthorized"}`（PASS=10 FAIL=19），但 exchange "服务 JWT 换取成功"；8081 重启到新代码后依旧。
- **根因①（主）**：脚本 `AUTH_HDR` 在**函数定义区静态构造**（96-100 行：`if [ -n "$JWT" ]` 判断发生在 exchange 之前、JWT 恒空）→ `AUTH_HDR` 定死为 `Authorization: Bearer <每机token>`；`exchange_jwt`（后调用）只设置 `JWT` 变量**不回写 AUTH_HDR** → 所有 MCP 调用拿"每机 token 当 JWT"送进 JwtDoctorAuthenticator（双密钥都解不开）→ INVALID_JWT。08-17/18 时 PASS=6 是因为当时 jwt-enabled=false（旧 token 形态恰好可用）。**修复**：exchange_jwt 内成功后回写 `AUTH_HDR="Authorization: Bearer $JWT"`。
- **根因②（辅）**：curl.exe 输出 CRLF → MSYS grep/sed 提取的 JWT 变量尾部残留 `\r` → 签名校验失败（同 INVALID_JWT）。**修复**：提取后 `JWT=$(printf '%s' "$JWT" | tr -d '\r')`。
- **排查技巧**：PowerShell 手动 `curl.exe exchange → ConvertFrom-Json 取 token → curl initialize` 得到 HTTP 400（鉴权已过、400 是 MCP 协议层）→ 反证后端正常、脚本变量传递是病根；日志 `Failed to deserialize message: Unexpected character ('j' (code 106))` 是 body 引号被剥/乱码的 Jackson 信号。
- **根因③（isError 误报）**：脚本"正常提交未标记 isError"断言用 `grep -q 'isError'` 宽匹配——**正常 MCP 信封自带 `"isError":false` 字段** → 恒误报 FAIL。**修复**：改 `grep -q '"isError":true'`（拒绝类场景 C/T/U/G 的宽匹配保留原样，语义是"error 或 isError 均可"）。

### 2026-08-14 sqlplus 批量导出脚本的三个坑（生产诊断分析数据提取）
- **PROMPT 行尾不能带 `--`**：sqlplus 把 `--` 当注释吞掉行尾换行符，导致下一行 SQL 首行被合并进注释行，报 SP2-0734（"未知的命令开头 FROM ..."）。PROMPT 行改用 `====` 或纯文本分隔。
- **NLS_LANG 不设置导致中文 LIKE 全空**：sqlplus 客户端字符集与库不一致时，`WHERE PromptTemplateName IN ('诊断分析','鉴别诊断分析')` 匹配为空、导不出数据且无报错。执行前必须 `set NLS_LANG=SIMPLIFIED CHINESE_CHINA.AL32UTF8`（已内置 run_extract.bat）。
- **ORA-64203 目标缓冲区太小**：`SUBSTR(TO_CHAR(CLOB),1,2000)` 组合报错；导出 CLOB 大字段直接用 CLOB 列 + `SET LONG 200000000 / SET LONGCHUNKSIZE 200000000 / SET LINESIZE 32767`，不要先 TO_CHAR。
- **SPOOL 单行导出需转义**：换行/制表符转义用 `\u000A`/`\u0009`（而非 `\n`/`\t`，避免与原文字面量冲突），分隔符 `|#|` 内容中出现时替换为 `¦#¦`（Python 侧 unescape 还原）。

### 2026-08-17 主服务器(100.66.1.3)前端无法连接执行服务器(100.66.1.4:8082)：Vue CLI proxy 正则"包含匹配"把 /execution/api/* 误转发到主后端
