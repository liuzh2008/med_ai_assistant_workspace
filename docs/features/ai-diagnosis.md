# AI辅助诊断

> 像一位随时待命的资深专家，帮助医生快速理清诊疗思路，减少遗漏和偏差。

## 核心能力

- **自动分析病历**：系统读取患者主诉、现病史、既往史、检查检验结果等信息，自动生成病情摘要，帮助医生快速把握全貌。
- **鉴别诊断建议**：根据当前病历信息，智能推荐可能的鉴别诊断方向，拓宽医生思路。
- **并发症风险识别**：提示患者潜在并发症风险，帮助医生提前防范。
- **诊断编辑面板**：医生可直接在界面上对AI建议的诊断进行确认、修改或补充，操作直观便捷。

## 使用场景

| 场景 | 价值 |
|------|------|
| **入院评估** | 快速生成患者病情摘要，辅助主管医师制定初步诊疗方案 |
| **查房分析** | 实时更新病情变化，提示新的诊断可能和风险点 |
| **诊断完善** | 帮助年轻医生补充遗漏诊断，提升病历诊断完整性 |

## 关键特性

- **多模型切换**：支持根据医院需求选择不同的AI模型，灵活适配不同场景。
- **流式响应**：AI分析结果逐字呈现，医生无需等待，阅读体验流畅自然。
- **AI仅为辅助**：所有诊断建议均需医生审核确认后方可纳入病历，最终决定权始终掌握在医生手中。

## 临床价值

AI辅助诊断不是替代医生的判断，而是作为得力助手，帮助医生在繁忙的临床工作中节省时间、拓宽思路、减少遗漏，从而提升诊断效率和完整性，让患者获得更精准的诊疗服务。
