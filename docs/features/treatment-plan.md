# 诊疗计划生成

> AI起草、医生把关、一键执行，让每日诊疗计划从繁琐变为高效。

## 核心功能

### AI自动生成结构化诊疗计划

系统根据患者病情和诊断，自动生成涵盖以下类别的结构化诊疗计划：

- **药物治疗**：用药名称、剂量、频次、疗程建议
- **检查项目**：推荐复查或新增的检查检验
- **护理措施**：护理级别和重点注意事项
- **手术安排**：手术建议和术前准备事项

### 可编辑表格

AI生成的每一项计划内容均以表格形式呈现，医生可以：

- **确认**：认可该条目，纳入正式诊疗计划
- **修改**：调整剂量、频次或更换方案
- **删除**：移除不适用的建议

医生拥有完全的主导权，AI仅为辅助起草。

### 连续性迭代

每次生成新的诊疗计划时，系统会自动提取医生上次确认的内容作为基础，在此基础上根据病情变化进行调整。医生无需从头编写，只需关注变化部分。

### 一键转待办

确认后的诊疗计划可一键生成待办任务清单，分配到相应科室或人员，确保计划落地执行。

### 分类标记

每条计划条目自动标注：

| 维度 | 说明 |
|------|------|
| **项目类型** | 药物 / 检查 / 护理 / 手术 |
| **重要性分级** | 一般 / 重要 / 紧急 |

帮助医护团队快速识别优先事项。

## 使用场景

- **每日诊疗计划**：主管医生查房后快速制定当日诊疗安排
- **多科室协作**：跨科室会诊时，各方建议统一整合为一份可执行计划
- **交接班**：AI提取已有计划，接班医生快速掌握后续安排

## 临床价值

诊疗计划生成模块将医生从重复性的文书工作中解放出来，让宝贵的时间回归临床诊疗本身，同时确保计划的规范性和完整性。
