# 数据采集建议

> 系统像一位经验丰富的上级医生，在接诊时提醒你还缺哪些关键信息。

## 功能概述

AI在分析患者已有信息后，智能推荐还需要进一步采集的数据，帮助医生构建更完整的病历信息。建议内容按结构化分类呈现，清晰有序。

## 结构化分类

系统推荐的采集方向分为四大类别：

| 类别 | 内容示例 |
|------|---------|
| **问诊** | 补充现病史细节、既往手术史、家族遗传病史、过敏史等 |
| **查体** | 建议补充的体格检查项目，如神经系统查体、专科查体等 |
| **辅助检查** | 推荐完善的检验、影像、心电图等检查项目 |
| **其他** | 心理评估、营养评估、功能评分等补充信息 |

## 两级折叠展示

为保持界面简洁，建议内容采用两级折叠设计：

- **第一级**：按上述四大类别分组，医生可按需展开查看
- **第二级**：每个类别下展开具体建议条目，条目简洁明了

医生可根据实际情况选择性采纳，无需全部执行。

## 临床价值

- **提升诊断完整性**：减少因信息采集不全导致的诊断遗漏
- **提高诊断准确性**：关键信息补充到位，诊断依据更充分
- **规范病历书写**：引导医生按标准流程采集信息，病历更规范

## 使用场景

| 场景 | 作用 |
|------|------|
| **门诊初诊** | 帮助门诊医生快速梳理问诊思路，不遗漏关键信息采集 |
| **住院补充检查** | 入院后系统根据已有资料推荐完善项，辅助完善入院评估 |

## 管理价值

对于医院质量管理而言，数据采集建议功能有助于：

- 统一不同医生的信息采集标准
- 降低因信息缺失导致的病历缺陷率
- 提升年轻医生的规范化诊疗能力
