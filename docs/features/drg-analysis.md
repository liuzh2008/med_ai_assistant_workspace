# DRG分析

> 自动匹配DRG分组，实时呈现医保盈亏，让医院DRG管理从被动应对变为主动掌控。

## DRG自动匹配

系统采用三级匹配策略，帮助医院精准锁定DRG分组：

| 匹配层级 | 说明 |
|---------|------|
| **精确匹配** | 诊断名称与DRG目录完全一致，直接锁定分组 |
| **名称包含匹配** | 诊断名称包含关键词，缩小候选范围 |
| **相似度匹配** | 基于语义相似度，推荐最接近的分组 |

同时，系统区分**有手术**和**无手术**两种路径分别匹配，确保分组逻辑与临床实际一致。

## MCC/CC智能筛查

系统内置超过 **12,000 条** MCC（主要并发症/合并症）和 CC（并发症/合并症）字典，自动识别病历中符合MCC/CC条件的诊断条目，帮助医院：

- 不遗漏可入组的并发症编码
- 提升DRG分组的准确性
- 合理反映病例复杂程度

## 盈亏实时计算

每份病例的DRG分组结果旁，直观显示医保付费与实际成本的对比：

- **绿色**：医保盈余，病例盈利
- **红色**：医保亏损，成本超支

医生和管理者可据此调整诊疗策略，优化成本结构。

## 关键成效

| 指标 | 效果 |
|------|------|
| 诊断编码完整率 | 提升 **30~50%** |
| 医保收益优化 | 提升 **10~20%** |

## 典型场景

- **出院结算前**：复核DRG分组是否准确，避免编码遗漏导致医保损失
- **医保政策调整后**：快速更新分组规则，确保医院适应新政策环境

## 管理价值

DRG分析模块帮助医院管理者从"事后算账"转向"事前预警"，精准掌握各科室、各病种的盈亏分布，为资源配置和绩效考核提供数据支撑。
