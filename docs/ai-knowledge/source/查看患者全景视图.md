# 查看患者全景视图

## 适用场景
- 查看患者的基本信息、诊断和手术记录
- 查看病情小结、病历、医嘱、检查、化验等各类诊疗数据
- 查看DRG分析结果和临床指引

## 操作步骤

1. 在左侧患者列表中点击某位患者，右侧即显示该患者的完整信息
2. 通过顶部标签页切换查看不同维度的数据：

| 标签页 | 内容说明 |
|-------|---------|
| 基本信息 | 患者身份信息、诊断列表、手术列表 |
| 病情小结 | 最近一次病情小结或查房记录 |
| AI诊断 | AI辅助分析诊断 |
| 临床指引 | 对应病种的临床诊疗指引 |
| 病历记录 | 全部病历文书 |
| 长期医嘱 | 正在执行的长期医嘱 |
| 临时医嘱 | 临时开具的医嘱 |
| 检查 | 各类检查报告及结论 |
| 化验 | 化验检验结果，异常值高亮显示 |
| DRG分析 | DRG分组和盈亏分析 |

### 诊断/手术管理（基本信息标签页）
- 诊断列表和手术列表并排展示
- 双击诊断或手术名称进入编辑
- 右上角有「新增」按钮添加新诊断或手术
- 手术列表配有「重新分析」按钮，可让AI自动从HIS操作记录中提取手术名称
- 主诊断/主手术有红色标记

## 注意事项
- 选择患者后，所有标签页的数据会自动加载
- 病危患者行红色背景，病重患者行黄色背景
- 费用和DRG数据可能需要几秒钟加载

## 常见问题

### Q: 切换患者后数据没有刷新？
A: 大部分数据会自动刷新。如发现数据未更新，可先点其他患者再点回来。

### Q: 诊断/手术编辑后没保存？
A: 编辑后需要点击对勾按钮或按 Enter 键确认，点击其他地方或按 Esc 会取消编辑。
