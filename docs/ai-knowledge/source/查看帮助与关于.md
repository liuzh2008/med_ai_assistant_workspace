# 查看帮助与关于

## 适用场景
- 首次使用系统，需要了解系统功能和操作指南
- 遇到使用问题，需要查阅帮助文档
- 查看系统版本信息和版权声明
- 向开发团队提交意见反馈

## 操作步骤

### 查看帮助文档
1. 点击顶部菜单「帮助」→「帮助文档」
2. 进入帮助文档页面，按分类浏览操作指南：
   - **临床质控**：AI质控评估和病种匹配的使用说明
   - **AI辅助**：AI诊断、诊疗计划、逻辑推理等功能说明
   - **病历管理**：病历记录、语音录入、草稿管理说明
   - **DRG分析**：DRG分组、盈亏分析的说明
   - **手术管理**：手术任务、手术字典的使用说明
3. 在页面左侧的导航目录中点击感兴趣的主题
4. 右侧显示该主题的详细说明内容
5. 页面顶部支持关键词搜索功能

### 查看意见反馈
1. 点击顶部菜单「帮助」→「意见反馈」
2. 进入反馈页面，填写反馈内容
3. 选择反馈类型（功能建议 / 问题报告 / 使用咨询）
4. 点击「提交」按钮
5. 反馈将发送给系统开发团队

### 查看关于信息
1. 点击顶部菜单「帮助」→「关于」
2. 显示系统版本信息、版权声明和技术支持联系方式

## 注意事项
- 帮助文档内容会随系统版本更新持续完善
- 意见反馈提交后，开发团队会定期处理，但不提供实时回复
- 如遇紧急问题，建议直接联系系统管理员

## 常见问题

### Q: 帮助文档找不到需要的内容？
A: 可使用页面顶部的搜索功能，输入关键词查找相关主题。如果仍找不到，可通过意见反馈告知我们。

### Q: 提交的反馈多久会有回应？
A: 反馈会定期收集处理。如果是紧急问题，建议先联系系统管理员或技术支持团队。

### Q: 系统更新后帮助文档会自动更新吗？
A: 是的，帮助文档会随系统更新同步发布新版本。
