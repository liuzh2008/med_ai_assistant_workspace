# 切换全屏与小屏模式

## 适用场景
- 需要更大的工作区域查看患者数据
- 在7-8英寸小屏设备（如平板）上使用系统
- 演示或汇报时需要全屏展示

## 操作步骤

### 切换全屏模式
1. 点击顶部菜单「系统」→「全屏」
2. 浏览器进入全屏模式，系统界面占满整个屏幕
3. 在全屏模式下，再次点击「系统」→「退出全屏」即可退出
4. 也可以按键盘 `Esc` 键退出全屏

### 切换小屏模式
1. 点击顶部菜单「系统」→「小屏界面」
2. 系统界面切换为小屏适配布局，针对7-8英寸设备优化
3. 再次点击「系统」→「小屏界面 ✓」可切换回标准模式

### 小屏模式特性
- 患者列表以紧凑方式显示
- AI辅助页面的Prompt模板列表可折叠/展开
- 患者全景视图的标签页区域适配小屏
- 诊断/手术信息等卡片区域自动调整布局

## 注意事项
- 小屏模式在小屏设备上默认显示，大屏设备需手动开启
- 全屏模式依赖于浏览器支持，部分浏览器可能需要用户手动确认
- 小屏模式会改变部分页面布局，某些功能入口可能变更位置

## 常见问题

### Q: 点击全屏后没有反应？
A: 部分浏览器需要用户点击确认才能进入全屏。请检查浏览器地址栏附近是否有全屏提示。

### Q: 小屏模式下有些按钮找不到了？
A: 小屏模式会把部分控制项收纳到可展开的面板中（如Prompt模板列表），请留意页面上的展开/收起按钮。

### Q: 如何判断当前是否在小屏模式？
A: 顶部菜单「系统」→「小屏界面」选项后如果有 ✓ 标记，表示当前已开启小屏模式。
