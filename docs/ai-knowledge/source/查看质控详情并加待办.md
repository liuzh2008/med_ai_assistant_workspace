# 查看质控详情并加待办

## 适用场景
- 查看质控评估的详细指标和完成情况
- 将未完成的质控指标加入待办事项

## 操作步骤

### 查看质控详情
1. 在「临床指引」标签页的底部工具栏，点击「查看详情」按钮
2. 右侧弹出**质控评估详情抽屉**（覆盖大部分页面）
3. 抽屉顶部显示确认的病种标签、完成进度和上次评估时间
4. 抽屉内按病种展示所有质控指标卡片
5. 可通过上方筛选按钮筛选：全部 / 已完成 / 未完成 / 数据不足

### 将指标加入待办
1. 在质控详情抽屉中选择一条未完成的指标
2. 点击指标卡片上的「加入待办」按钮
3. 系统弹出确认提示，确认后该指标内容会被创建一个待办事项
4. 可在待办事项页面查看和管理

## 注意事项
- 只有选中具体的质控指标后，「加入待办」按钮才可点击
- 质控详情抽屉关闭后，下次打开会重新加载最新数据

## 常见问题

### Q: 详情抽屉中的进度条颜色代表什么？
A: 进度条颜色根据完成率变化：完成率高为绿色，中等为黄色，低为红色。

### Q: 加待办后在哪里查看？
A: 点击顶部菜单「AI辅助」→「待办事项」即可查看所有待办事项。
