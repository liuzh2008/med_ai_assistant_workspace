# 新建手术任务

## 适用场景
- 需要为该患者新增一个手术任务
- 新增任务后供AI管理（完成状态、生成文书等）

## 操作步骤
1. 进入患者全景视图的「手术任务」标签页
2. 在页面中间的手术信息卡片上方，点击「新建」按钮
3. 系统清空表单，准备新增模式
4. 填写手术信息：
   - **手术名称**：输入手术名称（可从手术字典选择）
   - **手术日期**：选择日期
   - **麻醉方式**：输入或从列表中选择
   - **术前讨论主持/参加者**：填写人员信息
   - **手术风险评估**：填写评估内容
5. 填写完成后，点击「保存」按钮
6. 保存成功后，手术日期列表会刷新显示新记录

## 注意事项
- 手术名称支持从手术字典树形选择，点击输入框会自动弹出字典树
- 必填字段：手术名称、手术日期

## 常见问题

### Q: 保存后没看到新任务？
A: 请确认所有必填字段已填写，保存成功后会提示"保存成功"并刷新列表。

### Q: 手术名称从哪里来？
A: 可直接手动输入，也可以从手术字典中选择标准手术名称（点击手术名称输入框会弹出手术字典树）。
