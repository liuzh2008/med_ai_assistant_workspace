# 快速入门

## 系统简介

医疗AI辅助系统是专为基层医院打造的智能诊疗辅助平台，将人工智能技术融入日常临床工作。系统覆盖AI诊断分析、DRG医保分组分析、病历质量管控、智能诊疗计划等核心功能，帮助医生提升诊疗效率和病历质量，助力医院实现精细化管理。

## 登录系统

- 打开浏览器，输入系统地址（由医院信息科提供）
- 在登录页面输入您的账号和密码
- 首次登录后，建议立即修改初始密码，确保账户安全

## 主界面概览

登录后，您将看到系统的主界面，主要分为三个区域：

- **患者列表**：左侧展示当前科室的在院患者，可按床位、状态筛选
- **AI助手面板**：右侧是智能分析区域，可随时调用AI进行诊断分析、质控评估等
- **功能导航**：顶部菜单栏可切换至各功能模块，如患者管理、质控中心、DRG分析等

## 典型工作流程

系统贯穿患者诊疗全周期，以下是三个典型工作场景：

### 1. 入院评估

患者入院后，选择该患者 → 点击"AI诊断"，系统自动分析已有病历和检查数据 → 查看AI生成的病情摘要和诊断建议 → 在诊断编辑面板中对比、确认或调整诊断

### 2. 日常查房

查房结束后，录入查房记录 → 系统自动生成或更新诊疗计划 → 查看AI推荐的药物、检查、护理等措施 → 逐条确认或修改，一键转为待办事项

### 3. 出院管理

患者出院前，点击"DRG分析" → 系统匹配医保分组并显示支付标准 → 查看是否有遗漏的诊断编码（MCC/CC）→ 优化完善诊断编码 → 确认预期盈亏情况，完成出院结算
