# 帮助文档

## 常用工作流

快速了解系统核心操作流程：

| 功能 | 操作指引 | 帮助文档 |
|------|---------|----------|
| 🤖 **AI诊断** | 查看AI诊断分析结果 → 双击编辑诊断名称 → 勾选并添加到目前诊断 | [详细说明 →](/help/ai-diagnosis) |
| 🎙️ **病历记录编辑** | 打开病历记录页 → 点击语音录入按钮 → 口述内容，AI自动修正为规范医疗文本 | [详细说明 →](/help/medical-records) |
| 📝 **临床指引** | 查看AI生成的诊疗计划 → 将诊疗项目添加到待办事项或病历记录中 | [详细说明 →](/help/clinical-guidance) |
| 🔍 **质控详情** | 查看各病种质控指标完成情况 → 将未完成指标添加为待办事项或关联病历记录 | [详细说明 →](/help/qc-detail) |
| 🏥 **生成手术相关病历** | 打开任务对话框 → 切换到手术任务标签页 → 填写手术信息 → 点击任务名称执行 AI 生成文书 | [详细说明 →](/help/surgery-task) |
| 💊 **AI辅助（查房记录）** | 查看已执行Prompt列表 → 选择查房记录结果 → 审核和编辑AI生成内容 | [详细说明 →](/help/ai-assistant) |

## 帮助文档目录

以下是系统各功能模块的详细操作说明：

### 基础操作

- **[登录系统](/help/login)** — 账号登录、密码修改、安全退出
- **[患者管理](/help/patient)** — 患者列表、搜索筛选、查看详情
  - [基本信息](/help/basic-info) — 患者基本信息、手术记录管理
  - [病情小结](/help/patient-summary) — 每日自动生成的病情总结
- **[待办事项](/help/todo)** — 创建、跟踪、完成待办任务
- **[手术任务](/help/surgery-task)** — 手术计划管理、术前讨论、手术相关任务执行

### AI 智能功能

- **[AI诊断](/help/ai-diagnosis)** — AI诊断分析、逻辑推理、诊断编辑与管理
- **[AI辅助](/help/ai-assistant)** — Prompt模板执行、AI结果查看与编辑
- **[病历记录](/help/medical-records)** — 病历文书编辑、语音识别录入、草稿管理

### 质控与 DRG

- **[病历质控](/help/qc)** — 质控评估概览、问题列表与整改
- **[DRG分析](/help/drg)** — DRG分组匹配、医保盈亏分析
- **[临床指引](/help/clinical-guidance)** — 病种匹配、诊疗计划管理
  - [质控详情](/help/qc-detail) — 质控指标详情、待办关联
