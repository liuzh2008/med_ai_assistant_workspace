# 质控详情

## 适用场景

- 查看患者所有已确认病种的质控指标评估结果
- 按完成状态（已完成/未完成/数据不足）筛选查看指标
- 查看单个指标的判断依据、临床建议和冲突说明
- 将质控指标内容添加为待办事项
- 保存当前质控评估结果作为记录

## 操作步骤

### 1. 进入质控详情抽屉

![质控详情概览](/med_ai_assistant_workspace/screenshots/help/qc-detail/drawer-overview.png)

在**临床指引**页面底部工具栏中，点击**"查看质控详情"**按钮，从右侧打开质控详情抽屉。抽屉采用左右双栏布局：

- **左侧**：按病种分组的质控指标表格，每行显示病种名称、指标名称、完成状态图标和紧急程度图标
- **右侧**：选中指标后的详情卡片，显示判断依据、临床建议等内容
- **顶部**：汇总信息栏，展示已确认病种标签、完成进度条和最新评估时间

同一病种下的指标自动合并单元格，并按紧急程度（高→中→低）排序。

### 2. 查看顶部汇总信息

![抽屉头部汇总](/med_ai_assistant_workspace/screenshots/help/qc-detail/drawer-header.png)

抽屉顶部汇总区域展示：

- **已确认病种标签**：当前患者已确认的所有病种，以蓝色标签形式展示
- **完成进度条**：根据完成率百分比显示不同颜色（≥80% 绿色，≥60% 橙色，<60% 红色）
- **完成统计**：显示"已完成数/总指标数 项完成"，直观了解整体评估进度
- **评估时间**：显示最近一次质控评估的时间
- **保存记录按钮**：将当前评估结果持久化保存到数据库

### 3. 按状态筛选指标

![按状态筛选](/med_ai_assistant_workspace/screenshots/help/qc-detail/filter-by-status.png)

在筛选栏中，可通过单选按钮组按状态筛选指标：

- **全部**：显示所有状态的指标（默认）
- **已完成**：仅显示合规指标（绿色标识）
- **未完成**：仅显示不合规指标（红色标识）
- **数据不足**：仅显示因数据不足无法评估的指标（灰色标识）

筛选后表格自动刷新，仅显示符合条件的指标行，方便快速定位关注的问题指标。

### 4. 选中指标查看详情

![选中指标](/med_ai_assistant_workspace/screenshots/help/qc-detail/indicator-selected.png)

点击左侧表格中的任意指标行，该行高亮显示，右侧详情卡片同步展示该指标的完整评估信息：

- **判断依据**：AI 对该指标的评估依据和判断过程
- **临床建议**（仅未完成指标显示）：针对不合规情况的改进建议
- **冲突说明**（有冲突时显示）：指标评估中的冲突信息说明
- **完成时限**：该指标的完成期限要求
- **目标值**：该指标的目标值或目标范围

未选中任何行时，右侧面板显示"请选择左侧表格中的指标查看详情"引导提示。

### 5. 查看指标详情卡片

![详情卡片](/med_ai_assistant_workspace/screenshots/help/qc-detail/detail-card.png)

详情卡片以结构化方式展示选中指标的完整评估信息：

- **判断依据**区域（灰色背景）：AI 评估该指标时的判断依据和病历数据引用
- **临床建议**区域（橙色提示）：仅对未完成指标显示，给出具体的改进建议
- **冲突说明**区域（红色提示）：当指标评估存在冲突时，显示冲突的详细说明
- **附加信息**：完成时限和目标值等元数据

### 6. 添加待办事项

![添加待办](/med_ai_assistant_workspace/screenshots/help/qc-detail/add-todo.png)

在筛选栏右侧，点击**"待办"按钮**（黄色，需先选中一个指标行），可将当前指标的评估内容添加为待办事项：

- 自动读取选中指标的项目描述和判断依据作为待办内容
- 同一患者+同一内容仅保存一条，重复添加会提示"该内容已添加为待办"
- 添加成功后弹出成功提示

### 7. 保存评估记录

![保存记录](/med_ai_assistant_workspace/screenshots/help/qc-detail/save-record.png)

点击抽屉顶部汇总区域的**"保存记录"**按钮，将当前质控评估结果持久化保存到数据库：

- 保存成功后弹出"保存成功"提示
- 保存时传递关联的 Prompt 结果 ID，确保每次保存对应到具体的评估记录
- 保存按钮仅在具备患者 ID、评估结果和 Prompt 结果 ID 时可用

## 注意事项

- 质控详情抽屉需先进入临床指引页面，再点击底部工具栏的"查看质控详情"按钮打开
- 未选中指标行时，右侧详情卡片为空，待办按钮也为禁用状态
- 筛选切换后，之前选中的指标行会自动取消选中，需重新单击查看详情
- 添加待办需要先选中一个指标行，否则待办按钮为禁用状态
- 同一指标的判断依据和临床建议可能较长，右侧卡片支持滚动查看完整内容

## 常见问题

### Q: 质控详情抽屉无法打开？

A: 请确保已选中患者并进入临床指引页面，底部工具栏的"查看质控详情"按钮需要当前患者已有病种匹配和质控评估结果才可点击。

### Q: 筛选条件切换后看不到任何指标？

A: 如果切换到"未完成"或"数据不足"筛选后表格为空，说明当前评估结果中没有对应状态的指标，可切换回"全部"查看所有指标。

### Q: 如何查看指标的完整判断依据和临床建议？

A: 在左侧表格中单击选中该指标行，右侧详情卡片会自动展示该指标的判断依据、临床建议和冲突说明等完整信息。如果内容较长，滚动右侧面板即可查看全部内容。

### Q: 保存记录有什么作用？

A: 保存记录将当前质控评估结果持久化到数据库，确保评估结果不会因页面刷新或重新评估而丢失。每次保存对应一个具体的 Prompt 结果记录。

### Q: 已保存的记录在哪里查看？

A: 保存后的记录与当前患者的质控评估关联，后续再次打开质控详情抽屉时，会优先从已保存记录加载评估结果。
