# 基本信息

## 适用场景
- 查看当前选中患者的个人基本信息和诊疗数据
- 查看患者总费用和医保盈亏情况
- 管理患者的诊断列表（新增、编辑、删除、设为主要诊断）
- 管理患者的手术列表（新增、编辑、删除、设为主要手术、重新分析）
- 了解患者已选DRG分组编码

## 操作步骤

### 1. 基本信息概览

![基本信息概览](/screenshots/help/basic-info/basic-info-overview.png)

在患者管理页面选中左侧列表中的任意患者后，右侧默认显示"基本信息"标签页。页面分为三个区域：

- **患者信息卡片**：展示患者的核心身份信息和费用数据
- **诊断列表**：展示患者的诊断信息，支持编辑操作
- **手术列表**：展示患者的手术信息，支持编辑操作

标签栏包含多个功能标签页（基本信息、病情小结、AI诊断、临床指引、病历记录等），点击即可快速切换。

### 2. 查看患者详细信息

![患者详细信息](/screenshots/help/basic-info/patient-details.png)

患者信息卡片展示了以下核心数据：

- **ID**：患者住院编号
- **姓名**：患者姓名
- **性别**：患者性别
- **年龄**：患者年龄（自动根据出生日期计算）
- **入院时间**：患者入院日期和时间
- **DRG（已选）**：已选择的DRG分组编码（蓝色显示，如需查看详情请在DRG分析标签页操作）
- **总费用**：住院期间总费用，带千分位格式化显示
- **盈亏**：医保盈亏金额，正数（绿色）表示盈利，负数（红色）表示亏损

> 提示：悬停盈亏金额可查看详细说明（正数表示盈利，负数表示亏损）。

### 3. 管理诊断列表

![诊断列表](/screenshots/help/basic-info/diagnosis-list.png)

诊断列表以表格形式展示患者的诊断信息：

- **主诊断**：红色背景行高亮显示，诊断文本加粗，带有红色"主诊断"标签
- **普通诊断**：白色背景，以列表形式展示
- **双击编辑**：双击任意诊断行可进入编辑模式，修改诊断文本
- **操作按钮**（编辑模式下显示）：
  - **保存**（绿色勾）：保存修改的诊断文本
  - **删除**（红色叉）：删除该诊断（需二次确认）
  - **主诊断**（黄色星标）：将当前诊断设为主要诊断，或取消主诊断
  - **取消**（灰色叉）：取消编辑，恢复原值

在诊断列表底部点击 **圆形加号按钮（+）** 可新增诊断，输入诊断文本后点击保存即可。按 `Esc` 键或在编辑区域外点击可退出编辑模式。

### 4. 管理手术列表

![手术列表](/screenshots/help/basic-info/surgery-list.png)

手术列表以表格形式展示患者的手术信息：

- **主手术**：红色背景行高亮显示，手术名称加粗，带有红色"主手术"标签
- **手术日期**：灰色文字显示在手术名称后方
- **双击编辑**：双击任意手术行进入编辑模式，修改手术名称
- **操作按钮**（编辑模式下显示，与诊断列表类似）：
  - **保存**（绿色勾）：保存修改的手术名称
  - **删除**（红色叉）：删除该手术（需二次确认）
  - **主手术**（黄色星标）：设为主要手术或取消主手术
  - **取消**（灰色叉）：取消编辑，恢复原值

手术列表底部有两个操作按钮：

- **重新分析**（黄色刷新按钮）：调用AI接口重新分析患者的手术记录，手术名称为每天自动生成
- **新增手术**（绿色加号按钮）：手动新增手术记录

按 `Esc` 键或在编辑区域外点击可退出编辑模式。

## 注意事项
- 基本信息标签页是选中患者后的默认展示页，切换患者时会自动重置到该标签页
- 诊断和手术的编辑操作会实时提交到服务器，编辑后无需额外保存
- 删除诊断/手术操作不可恢复，系统会弹出确认对话框
- 盈亏计算依据DRG分组和实际费用自动计算，不同倍差区间计算规则不同
- 手术重新分析由AI驱动，触发后会弹出确认对话框
- 费用数据来源于医院信息系统（HIS），开发环境下会使用模拟数据

## 常见问题

### Q: 基本信息页面显示"暂无费用数据"怎么办？
A: 费用数据从医院信息系统获取，如显示"暂无费用数据"，请确认该患者是否有费用记录。开发环境下系统会自动生成模拟数据。

### Q: 如何修改诊断或手术内容？
A: 双击需要修改的诊断行或手术行，进入编辑模式后修改文本内容，点击保存按钮（绿色勾）即可提交修改。

### Q: 盈亏金额是如何计算的？
A: 盈亏 = 医保支付标准 - 实际总费用。根据费用与支付标准的倍差分段计算：
- 倍差 ≤ 0.7（低倍率）：结余为 0，显示黑色
- 0.7 < 倍差 ≤ 1（正常盈利）：绿色显示
- 1 < 倍差 < 1.4（正常亏损）：红色显示
- 倍差 ≥ 1.4（高倍率亏损）：按调整公式计算，红色显示

### Q: 手术列表为空怎么办？
A: 手术列表为空可能是因为尚未进行手术分析。点击底部的"重新分析"按钮（黄色刷新图标），系统会调用AI自动分析患者的手术记录。

### Q: 诊断/手术编辑后没有保存成功？
A: 请确认网络连接正常。如编辑后提示"保存失败"，可稍后重试。编辑内容不会自动缓存，请在修改后立即保存。
