# AI辅助

## 适用场景

- 医生需要查看患者已执行的 AI 分析结果时
- 对 AI 生成的内容进行审核、编辑和确认
- 利用系统预置的 Prompt 模板快速生成诊疗分析内容
- 需要复制 AI 结果到其他文档中引用时

## 操作步骤

### 1. 查看 Prompt 列表

在 AI 辅助页面中，左侧面板为 **Prompt 列表**，分为两个区域：

- **已执行 Prompt**：展示已完成的 AI 分析记录，包含标题和日期
- **未执行 Prompt**：展示等待执行的 AI 分析任务

![Prompt列表](/screenshots/help/ai-assistant/prompt-list.png)

已执行的 Prompt 可以直接点击查看详细内容。未执行的 Prompt 点击后会提示"该 Prompt 尚未执行完成，请等待执行结果"。

### 2. 查看 AI 结果

在已执行 Prompt 列表中点击任意一条记录，右侧会加载对应的 AI 结果内容。

- AI 结果以 Markdown 格式渲染，结构化展示分析内容
- 内容区域上方为 **操作工具栏**，包含编辑、删除、复制等功能按钮
- 底部（或内容区域下方）显示 AI **免责声明**："AI生成内容仅供参考，请医生审核后使用"

![查看AI结果](/screenshots/help/ai-assistant/ai-result.png)

### 3. 编辑内容

如果 AI 生成的内容需要调整，可以点击工具栏中的 **编辑内容** 按钮，切换到 Markdown 编辑模式。

- 编辑器支持 Markdown 语法，可直接修改文本内容
- 编辑完成后点击 **确定** 保存修改，点击 **取消** 放弃本次编辑
- 修改后的内容会覆盖原始 AI 结果，并记录修改人和修改时间

![编辑内容](/screenshots/help/ai-assistant/edit-content.png)

### 4. 删除 AI 结果

如果某条 AI 结果不再需要，可以点击工具栏中的 **删除AI结果** 按钮。

- 系统会弹出确认对话框，防止误操作
- 确认删除后，该结果将从列表中移除且不可恢复
- 取消操作可关闭对话框

![删除确认对话框](/screenshots/help/ai-assistant/delete-result.png)

### 5. 复制内容

需要将 AI 结果引用到其他文档时，可以点击工具栏中的 **复制** 按钮。

- 复制时自动去除内容中的回车键，使文本段落连续
- 复制后的内容适合粘贴到病历记录、会诊报告等文书中
- 如需保留原始 Markdown 格式的换行结构，请使用编辑功能手动复制

![复制操作](/screenshots/help/ai-assistant/copy-result.png)

### 6. 使用 Prompt 模板

点击页面右上角的 **Prompt模板** 按钮，可展开模板选择面板。

- 模板以树形结构组织，按类别分组（如入院记录、病程记录、会诊记录、日常对话等）
- 点击模板名称即可查看详情
- 双击或点击执行按钮，可基于所选模板生成新的 Prompt 分析任务
- 部分模板（如会诊记录、日常对话等）会弹出补充信息窗口，用户可输入额外的参考信息后执行
- 生成的 Prompt 会出现在"未执行 Prompt"列表中，等待后台处理完成

![Prompt模板面板](/screenshots/help/ai-assistant/prompt-templates.png)

### 补充信息输入

点击需要补充信息的模板（如请会诊记录、日常对话、转科记录等）后，系统会依次弹出两个对话框：

1. **确认对话框**：提示是否调用该模板进行分析，点击 **确定** 继续
2. **补充信息对话框**：显示文本输入框，可填写额外的参考信息

补充信息可为空直接跳过，也可输入具体说明内容（如会诊目的、需要解决的问题等）。

![补充信息窗口](/screenshots/help/ai-assistant/additional-info.png)

![已填写补充信息](/screenshots/help/ai-assistant/additional-info-filled.png)

点击 **确认** 提交补充信息后执行模板，点击 **跳过** 则不补充信息直接执行。新的 Prompt 会出现在左侧"未执行 Prompt"列表中，等待执行完成后即可查看 AI 分析结果。

## 注意事项

- **内容审核**：AI 生成的内容（包括通过模板生成的结果）仅供辅助参考，医生需要进行审核确认
- **编辑覆盖**：编辑内容会覆盖原始 AI 结果，建议在确认无误后再保存
- **删除不可恢复**：删除 AI 结果后数据无法恢复，请谨慎操作
- **模板执行时间**：部分模板执行可能需要一定时间，请耐心等待处理完成

## 常见问题

### Q: 点击已执行 Prompt 后右侧没有显示内容？
A: 请确认该 Prompt 的状态为"已完成"。部分 Prompt 可能由于数据不足或处理异常导致内容为空，可尝试点击其他已执行 Prompt 查看。

### Q: 编辑内容后如何恢复到修改前？
A: 编辑保存后原始内容会被覆盖。如果需要保留原始内容，建议在编辑前先使用 **复制** 功能备份。

### Q: Prompt 模板执行后需要等待多久？
A: 执行时间取决于模板的复杂度和患者数据量。通常情况下，简单模板在几分钟内即可完成，复杂模板可能需要更长时间。完成后的结果会出现在"已执行 Prompt"列表中。

### Q: 复制按钮没有反应？
A: 请检查浏览器是否阻止了剪贴板访问权限。部分浏览器需要页面获得用户交互后才能访问剪贴板，可尝试重新点击复制按钮。
