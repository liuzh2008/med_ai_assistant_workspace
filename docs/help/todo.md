# 待办事项

## 适用场景

- 查看本科室所有患者按日期汇总的待办事项列表
- 快速筛选有待办的患者与全科患者列表对比
- 为指定患者新增待办事项（手动输入或从其他功能自动添加）
- 查看单个患者的全部待办事项，按时间倒序浏览
- 编辑或删除已有的待办事项

## 操作步骤

### 1. 打开待办事项弹窗

待办事项以弹窗形式展示，可通过以下四种方式打开：

**方式一：通过顶部导航菜单**

点击顶部导航栏「AI辅助」→「待办事项」，弹出待办事项对话框。弹窗打开后，自动根据当前用户所属科室和选中日期加载待办列表。

**方式二：通过右键快捷菜单**

在系统任意位置选中文字后右键，选择「添加到待办事项」，弹窗自动打开并预填选中文字为待办内容，同时关联当前选中的患者。

**方式三：从病历记录页面添加**

在病历记录页面，选中病历内容中的文字后，点击编辑工具栏上的 **待办按钮**（黄色备忘录图标），可直接将选中文字添加为待办事项。

**方式四：从诊疗计划表添加**

在临床指引页面的诊疗计划表中，点击操作列的 **待办按钮**（黄色备忘录图标），可将当前诊疗项目的描述和注意事项添加为待办事项。

### 2. 待办事项弹窗概览

![待办事项弹窗概览](/med_ai_assistant_workspace/screenshots/help/todo/todo-dialog-overview.png)

待办事项弹窗采用左右分栏布局：

- **左侧面板**（60%宽度）：包含顶部筛选区和病人卡片列表
- **右侧面板**（40%宽度）：显示选中病人的基本信息、新增待办输入区和全部待办列表

顶部标题栏显示当前筛选维度的名称（如科室名称）。

### 3. 筛选与浏览病人列表

![待办病人模式左侧面板](/med_ai_assistant_workspace/screenshots/help/todo/todo-left-panel.png)

左侧面板顶部提供两个筛选条件：

- **日期选择器**：选择一个日期，仅显示该日期的待办事项，默认选中当天
- **筛选维度下拉框**：
  - **待办病人**：仅显示当前科室有待办事项的患者（默认）
  - **全科**：显示当前科室全部患者（包含无待办的患者）

病人卡片列表按以下规则排列：

- **有待办的患者**排在前面，无待办的排在后面
- **同一组内**按床号升序排列

每张病人卡片展示：

- **[床号]**：蓝色加粗显示
- **姓名**：黑色加粗显示
- **待办预览**：显示该患者的待办事项摘要，仅展示以 `- [ ]` 开头的任务列表项

点击任意病人卡片，右侧面板切换为选中患者的详细信息。

### 4. 全科筛选模式

![全科筛选模式](/med_ai_assistant_workspace/screenshots/help/todo/todo-all-departments.png)

将筛选维度切换为「全科」后，左侧面板会显示当前科室的全部在院患者（含无待办患者）。该系统默认按「待办病人」模式显示，仅在需要对比查看全科患者待办覆盖情况时使用全科模式。

### 5. 查看患者详细信息

![选中患者查看详情](/med_ai_assistant_workspace/screenshots/help/todo/todo-patient-selected.png)

点击左侧患者卡片后，右侧面板顶部显示患者基本信息卡片：

- **[床号] 姓名 性别 / 年龄**
- **诊断信息**：展示该患者的所有诊断（从医院信息系统获取）

### 6. 新增待办事项

![新增待办](/med_ai_assistant_workspace/screenshots/help/todo/todo-add-new.png)

在右侧面板的「新增待办事项」区域：

1. 在文本框中输入待办事项描述（支持 Markdown 格式，最多 2000 字符）
2. 点击 **添加待办** 按钮（蓝色）
3. 系统自动以 `- [ ] ` 格式保存待办内容
4. 添加成功后弹出成功提示，待办列表自动刷新

> 如果通过右键菜单或病历记录中的选中文字打开弹窗，新增输入区会自动预填选中文字。

注意事项：
- 必须先选中一个患者，否则无法添加
- 同一患者 + 同一内容仅保存一条，重复添加会提示"该内容已添加为待办"
- 内容为空时添加按钮为禁用状态

### 7. 查看患者的全部待办事项

![待办事项卡片列表](/med_ai_assistant_workspace/screenshots/help/todo/todo-list-cards.png)

选中患者后，右侧面板下方展示该患者的全部待办事项列表：

- 每条待办事项以独立卡片展示
- **时间**：灰色文字显示创建时间（格式：`YYYY-MM-DD HH:mm`）
- **内容**：以 Markdown 格式渲染展示，支持任务列表复选框
- 待办事项按时间倒序排列，最新的在最上方

### 8. 编辑待办事项

![编辑待办](/med_ai_assistant_workspace/screenshots/help/todo/todo-edit-mode.png)

双击任意待办事项的内容区域，进入编辑模式：

1. 待办卡片变为蓝色边框高亮
2. 内容区域切换为文本编辑框
3. 修改待办内容后，使用操作按钮：
   - **保存**（绿色勾按钮）：保存修改
   - **删除**（红色叉按钮）：删除该待办（需二次确认）
   - **取消**（灰色叉按钮或按 `Esc` 键）：放弃修改，恢复原内容

### 9. 删除待办事项

在编辑模式下点击 **删除按钮**（红色叉），弹出确认对话框：

- 确认删除：该待办事项将被永久删除
- 取消：放弃删除操作

删除成功后弹出成功提示，待办列表自动刷新。

### 10. 从其他入口查看待办

病情小结页面会同步展示当前患者的**最近 2 条待办事项**，方便在不打开弹窗的情况下快速了解患者的待办情况。

## 注意事项

- 待办事项弹窗始终挂载在页面中，通过 prop 控制显隐，切换页面不会丢失编辑状态
- 待办事项按患者维度组织，必须先选择患者才能查看或添加待办
- 添加或编辑待办后列表会自动刷新，无需手动操作
- 删除操作不可恢复，请谨慎操作
- 日期筛选会影响待办列表的加载范围
- 全科模式下会额外加载无待办的患者，主要用于对比全院患者的待办覆盖情况

## 常见问题

### Q: 待办事项弹窗打开后左侧列表为空？

A: 请确认已正确加载用户信息和科室。弹窗打开时会自动从后端获取当前科室的待办数据。如果仍为空，请检查是否有患者有待办事项，或切换日期尝试。

### Q: 新增待办时提示"未选择病人"？

A: 新增待办前，需要先在左侧列表中点击选择一个患者。右侧面板只有选中患者后才能进行新增操作。

### Q: 如何将病历中的某段文字快速添加为待办？

A: 在病历记录页面中，选中目标文字后，点击编辑工具栏上的 **待办按钮**（黄色，带备忘录图标），系统会自动将选中文字创建为待办事项并关联当前患者。

### Q: 待办事项可以标记完成状态吗？

A: 待办事项内容支持 Markdown 任务列表格式（`- [ ]`），当前主要通过编辑方式手动更新内容或删除已完成的事项来管理状态。已完成的事项建议编辑或删除。

### Q: 待办事项的数据保存在哪里？

A: 待办事项数据存储在服务器端，与患者关联。不同科室、不同用户的待办数据独立存储，通过日期和科室参数查询加载。

### Q: 其他页面添加的待办会不会在这里显示？

A: 会的。无论在待办弹窗、病历记录页面、诊疗计划表还是临床指引/质控详情中添加的待办，都属于同一患者的待办事项，在待办弹窗中均能查看和管理。
