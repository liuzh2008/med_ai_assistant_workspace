#### 2.2 星火大模型内置联网搜索（`web_search` tool）—— 已核实

- **官方文档 URL**：https://www.xfyun.cn/doc/spark/X1ws.html （Spark-X2 WebSocket 协议文档，更新时间 2026.02.09）
- **接入形式**：WebSocket（`wss://spark-api.xf-yun.com/x2`，domain=`spark-x`），在 `parameter.chat.tools` 中传：
  `{"type":"web_search","web_search":{"enable":true,"search_mode":"normal"}}`
  - `search_mode`：`normal`（简要搜索）/ `deep`（深度搜索，信源更详细，prompt token 会膨胀）
- **计费方式（已核实）**：按 token 计费，响应 `usage.text.total_tokens` 即本次交互计费 token；deep 模式会额外产生 `search_prompt_tokens`（网页搜索膨胀的 token）并计入计费。
- **权威来源限定**：**未查证到**（该文档未提供站点白名单/域名限定参数，只有 `search_mode` 开关）。
- **Java 支持**：官方提供 Java Demo（文档页有 Java Demo 下载链接）。
- **注意**：这是「大模型 + 联网搜索」一体化能力，不是「给自有大模型调用的纯搜索 API」。若项目想「自己的模型 + 讯飞的搜索」，应选 2.1 的万搜 API。

#### 2.3 其他讯飞相关（已核实）

- **星火大模型可定制化 API**：https://www.xfyun.cn/doc/spark/OptionalAPI.html —— 官方服务介绍原文：「同时集成 RAG 和**联网搜索工具**，支持对公域和私域知识进行混合检索」。属「模型 + 联网搜索」形态，非独立搜索 API。
- 讯飞星火 Lite 版曾宣布永久免费（[新华网安徽](http://ah.xinhuanet.com/20240522/a8f52c70f42648dcbc39198c38fef388/c.html) 等新闻稿，**待核实**，且与搜索 API 无关）。
