## 三、本次增补的两条约束（用户要求）

### 3.1 Gate 1《诊断分析》新增「三、去重与命名规范」（原「三、」顺延为「四、」）

```
1.去重优先——已被疾病诊断覆盖的指标不得单独成条：
   若某检验/检查异常已作为诊断列表中某条疾病诊断的组成部分（其"诊断依据"已引用该指标，
   或该指标是该疾病的诊断标准/典型表现），则该指标不得再单独列为一条诊断，其内容并入该疾病诊断的"诊断依据"。
   - 错误示例："血葡萄糖升高"与"2型糖尿病"并存；"肌酐升高"与"慢性肾脏病3期"并存；
     "转氨酶升高"与"肝硬化"并存；"血钾升高"与"慢性肾脏病5期"并存。
   - 说明："异常不删"约束的是去留（不得删除客观异常），不等于允许重复列出已被疾病诊断覆盖的指标。
2.命名不得退化——客观异常条目一律优先使用疾病名称，禁止用纯"检验项目名+结果"代替可用的疾病名：
   - 血小板计数降低 → 血小板减少症；血钙降低 → 低钙血症；血钾降低/升高 → 低钾血症/高钾血症；
     血钠降低 → 低钠血症；血氯升高 → 高氯血症；血尿酸升高 → 高尿酸血症；
     白细胞计数降低 → 白细胞减少症；淋巴细胞计数降低 → 淋巴细胞减少症；
     血红蛋白降低 → 贫血；白蛋白降低 → 低白蛋白血症；
     总胆固醇或 LDL-C 升高 → 高胆固醇血症；甘油三酯升高 → 高甘油三酯血症
   ——仅当确实不存在对应疾病名称时（如"纤维蛋白原升高""碱性磷酸酶升高""糖化血红蛋白升高"、
     "脂蛋白(a)升高"、单项"肌酐降低"），才可使用检查异常类名称，并必须在补充说明写明
     "原因未明/临床意义有限，需进一步查明"。
3.括注不得承载检验结果（如"乙型肝炎病毒既往感染（乙肝表面抗原阴性、e抗体阳性、核心抗体阳性）"
   → "乙型肝炎病毒既往感染"，检验结果移入"诊断依据"）。
```

同时新增**错误示例 11**（指标异常与疾病诊断重复列出）、**错误示例 12**（命名退化）。

### 3.2 Gate 2《诊断审查》同步

- 审查决策矩阵新增 2 行：
  - `指标条目与既有疾病诊断重复` → **合并**（该重复条目不保留，指标并入疾病诊断依据），类别修正诊断；
  - `命名退化（用纯检验名代替可用疾病名）` → **重写为疾病名称**，类别修正诊断。
- 重要约束新增**第 11 条**：去重与命名退化检查（必做）——含括注不得罗列检验项目与结果。

### 3.3 临床规则库同步（4 条「检查异常条目规范」）

功能异常 / 指标升高 / 指标降低 / 阳性结果 4 条规则各追加 3 条补充规则（去重、命名优先疾病名、括注规范），与"异常不删"并列遵守。
