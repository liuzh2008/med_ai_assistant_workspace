# 经导管主动脉瓣置换术（TAVR）术前讨论记录通用模板

> **适用范围**：主动脉瓣狭窄（Aortic Stenosis，AS）与主动脉瓣关闭不全／反流（Aortic Regurgitation，AR）患者行经导管主动脉瓣置换术（Transcatheter Aortic Valve Replacement / Implantation，TAVR / TAVI）。
> **覆盖术式变体**：经股动脉入路（首选）、经颈动脉／锁骨下（腋）动脉／经升主动脉／经心尖入路；原生瓣 TAVR、二叶式主动脉瓣 TAVR、瓣中瓣（TAVR-in-SAVR、TAVR-in-TAVR）。
> **版本**：v1.2（2026-11-15）｜**状态：待医院审核**｜**编制**：AI 辅助整理，须经临床科室与医务／病案管理部门审定后方可正式使用。

---

## 〇、使用前必读（五条硬规则）

1. **本模板是结构骨架与判据来源，不是诊断结论。** 所有数值必须来自病历、检验、检查报告的原始记录；资料缺失时写"（资料未提供，待补充）"，**不得编造、不得用"正常""未见异常"填空**。
2. **不得删段。** 可按病例增补内容，但不得以"精简篇幅"为理由省略异常发现、支持手术指征的依据与关键阴性结果（异常项与依据必须全留）。
3. **时限**：术前讨论应在**手术医嘱开立之前**完成，且**早于手术知情同意书签署**；讨论记录应在讨论后 **24 小时内**完成，记录时间不得早于讨论时间。
4. **人员**：术者**必须参加**讨论并在参加人员中列名；四级手术由**科主任（或院内授权的高年资副主任医师）及以上**主持；TAVR 建议按**心脏团队（多学科，≥3 个学科）**形式开展，并同步留存《四级手术术前多学科讨论记录》（两者可互相引用，不得互相替代）。
5. **书写规范**：绝对时间（YYYY 年 MM 月 DD 日 HH:mm）、法定计量单位、规范中文术语；英文缩写首次出现须给全称。

### 与"补记"的边界

急诊 TAVR（心原性休克、药物难以纠正的血流动力学崩溃、持续性室速／室颤、需机械循环辅助的不稳定心绞痛或心衰）可先手术后补记，但**必须注明急诊原因与补记时间**，并按院内规定完成事后讨论留痕。

## 二、与现有《术前讨论记录》模板的对应关系

本院现有术前讨论 Prompt 模板为七段结构（术前准备情况／手术指征／拟手术名称／替代治疗方案／麻醉方案／可能出现的意外及防范措施／主持人小结意见）。本模板**不改变该七段骨架与输出顺序**，仅做三件事：补头部要素、把每段展开为可核对的数据项、增加"讨论结论"落地段。

| 现有段落 | 本模板位置 | 本模板的强化点 |
|---|---|---|
| （无） | 3.0 讨论头部 | 补手术级别、讨论形式、心脏团队学科构成、术者是否到场 |
| 术前准备情况 | 3.1 | 拆为"病情摘要／关键检查判读／检查完整性核对／风险评分／术前准备落实"五块，杜绝一段话糊过去 |
| 手术指征 | 3.2 | 按 AS／AR 两套判据逐条对照，并单列"禁忌证排除"与"中心／术者经验" |
| 拟手术名称（含植入物使用意见） | 3.3 | 必须落到"入路＋瓣膜类型＋型号＋选择依据＋超尺寸策略"，不能只写术名 |
| 替代治疗方案 | 3.4 | 必须做方案对比（SAVR／药物／球囊成形／保守），并写明本例为何不选 |
| 麻醉方案 | 3.5 | 由"局麻"改为按入路与病情分层（镇静／监护麻醉／全麻），并列循环支持预案 |
| 可能出现的意外及防范措施 | 3.6 | 按 TAVR 特有并发症逐项列"识别—预防—应急—责任人／设备" |
| 主持人小结意见 | 3.7 | 必须给出"准备是否充分、指征是否合理、方案是否确定、是否同意手术"四个明确判断 |
| （无） | 3.8 讨论结论 | 把结论落成可执行清单（人员分工、待办事项、备血／设备／ICU、术后重点） |

## 三、模板正文

### 3.0 讨论头部

| 字段 | 填写要求 |
|---|---|
| 讨论日期时间 | YYYY 年 MM 月 DD 日 HH:mm（与记录时间区分） |
| 讨论地点 | 具体到科室／会议室／杂交手术室 |
| 主持人 | 姓名＋科室＋专业技术职务（四级手术须科主任或院内授权的高年资副主任医师及以上） |
| 参加人员 | 逐人列"姓名＋科室＋专业技术职务"；**必须含术者**；建议覆盖心血管内科（结构性心脏病）、心脏外科、麻醉科、超声心动图／影像科、重症医学科；按需加血管外科、神经内科、肾内科、护理、体外循环／灌注 |
| 记录者 | 姓名＋专业技术职务 |
| 手术级别 | 四级（介入） |
| 讨论形式 | 科室讨论／院内多学科讨论（MDT）／心脏团队讨论；是否同时留存 MDT 记录及记录编号 |

### 3.1 术前准备情况

#### 3.1.1 病情摘要与诊断依据

- 主诉、现病史要点、症状演变（**按 NYHA 心功能分级**描述活动耐量，不写"一般情况可"这类无法核对的话）。
- 术前诊断（含瓣膜病变类型与程度，例："主动脉瓣狭窄（重度）""主动脉瓣关闭不全（重度）"）；合并症逐条列出（冠心病、房颤、慢性肾脏病、慢性阻塞性肺疾病、糖尿病、脑血管病、外周动脉疾病、肿瘤、衰弱等）。
- 既往史：心脏手术史（含既往 SAVR／TAVR、冠脉搭桥、起搏器／ICD）、过敏史（**尤其碘对比剂、抗血小板药、麻醉药**）、出血史、输血史。
- 当前用药：抗血小板／抗凝药（名称、剂量、末次服用时间、是否需停用或桥接）、降压药、利尿剂、降糖药。

#### 3.1.2 关键辅助检查判读（逐项写数值与结论，不得只写"异常"）

| 检查 | AS 必填项 | AR 必填项 |
|---|---|---|
| 超声心动图（TTE，必要时 TEE） | 最大流速 Vmax、平均跨瓣压差、瓣口面积 AVA、AVA 指数、LVEF、LVEDD／LVESD、合并反流程度、肺动脉压 | 反流程度与定量指标（缩流颈宽度、压力减半时间、反流容积／分数、有效反流口面积）、LVEDD／LVESD／LVESD 指数、LVEF、合并瓣膜病变、肺动脉压 |
| 心电门控全时相 CTA（主动脉根部＋全主动脉＋入路） | 瓣环面积／周长／最大最小径、瓣叶钙化分布与程度、LVOT 钙化、窦部直径与高度、左右冠开口高度、升主动脉径、瓣环—主动脉角度 | 同左，**另需**双锚定平面测量（瓣环、LVOT、升主动脉）与锚定分型（1～4 型） |
| 冠状动脉评估（冠脉造影或冠脉 CTA） | 有无显著狭窄、是否需要同期 PCI、左主干病变 | 同左 |
| 心电图／动态心电图 | 心律、PR 间期、束支传导阻滞、既往起搏器 | 同左 |
| 实验室 | 血常规、凝血功能、肝肾功能（eGFR）、电解质、BNP／NT-proBNP、心肌损伤标志物、血型与抗体筛查 | 同左 |
| 其他 | 肺功能、血气、颈动脉超声、衰弱与营养评估、认知与神经系统评估 | 同左 |

#### 3.1.3 术前检查完整性核对（缺项清单，逐项给状态）

按"已具备／待补／本院不开展"三态逐项核对：血常规、凝血、肝肾功能、电解质、BNP、心电图、超声心动图、CTA（根部＋入路）、冠脉评估、肺功能、颈动脉超声、血型与备血、感染筛查、口腔与皮肤准备。**缺项必须写进结论段并指定责任人与完成时限。**

#### 3.1.4 外科风险评分

- STS-PROM（%）与 EuroSCORE II（%），注明计算日期与所用版本；**未计算须写"未计算，原因：____"**，不得留空。
- 心脏团队对"外科禁忌／高危／中危／低危"的判定及依据（如：EuroSCORE II >8%、胸廓放疗史、主动脉瓷化、极度衰弱、肝功能衰竭等）。

#### 3.1.5 术前准备落实

备血（品种与数量）、抗栓药物停用／桥接方案与末次用药时间、预防性临时起搏电极、对比剂过敏预处理、肾功能保护（水化）、禁食禁饮、皮肤准备、术前用药、知情同意签署时间（须晚于讨论时间）、ICU 床位与设备预约。

### 3.2 手术指征

按以下六步逐条写，每步给出本例的具体依据（**不得只写"有手术指征"**）：

1. **病变严重程度**：按 4.1／4.2 判据表判定为重度（写明具体数值与判定标准来源）。
2. **症状与干预时机**：有症状者写明症状类型（劳力性呼吸困难、心衰、心绞痛、晕厥或晕厥先兆）与 NYHA 分级；无症状者写明满足哪一条客观条件（运动试验、LVEF、极重度指标、钙化进展、BNP 等）。
3. **外科手术风险与心脏团队决策**：STS-PROM／EuroSCORE II 数值＋外科禁忌或高危的具体理由；说明为何"外科手术风险高于 TAVR"。
4. **解剖适合性**：瓣环尺寸与钙化、冠脉阻塞风险、入路血管条件是否满足 TAVR 要求（写明关键测量值）。
5. **禁忌证排除**：逐条排除 4.3 的五条禁忌证（左室新鲜血栓、无纠正措施的左室流出道严重梗阻、急性心肌梗死不稳定期、主动脉根部解剖不适合、其他严重合并症致预期寿命不足 1 年）。
6. **预期获益与中心条件**：预计生存期 >1 年、预期生活质量改善；二叶式 AS 与单纯 AR 须写明**开展中心年手术量 ≥50 例或术者年手术量 ≥25 例**（符合共识要求）。

结论句示例："综合以上，本例具备 TAVR 指征，且无绝对禁忌证。"

### 3.3 拟手术名称与手术方案（含植入物使用意见）

| 要素 | 填写要求 |
|---|---|
| 手术名称 | 规范写法："经导管主动脉瓣置换术（经股动脉入路）"；瓣中瓣写"经导管主动脉瓣瓣中瓣置换术（TAVR-in-SAVR／TAVR-in-TAVR）"；不得写"TAVR 术""换瓣"等简写 |
| 入路 | 首选股动脉（90% 以上患者适用）；写明双侧股总动脉最小径、钙化与迂曲程度、穿刺点高度、有无替代入路（颈动脉／锁骨下（腋）动脉／经升主动脉／经心尖）及选择理由 |
| 人工瓣膜 | 类型（球囊扩张式／自膨胀式／可回收系统）、品牌与型号、规格；**必须写明选择依据**：瓣环测量值、钙化分布、二叶式解剖、冠脉阻塞风险、传导阻滞风险、瓣环破裂风险、瓣膜—患者不匹配（PPM）风险 |
| 超尺寸策略 | 球囊扩张式按瓣环面积／周长计算超尺寸率；单纯 AR 按双锚定平面直径（周长）计算，**超尺寸率建议 ≥10%**（共识要求） |
| 术中关键步骤 | 临时起搏电极植入、跨瓣与导丝选择、球囊预扩张／后扩张方案、瓣膜释放位置与角度、是否需要脑保护装置、是否需要冠脉保护、是否需要机械循环辅助 |
| 备选方案 | 术中转外科开胸、改换瓣膜型号、仅行球囊主动脉瓣成形、分期手术等，并写明触发条件 |
| 同期处理 | 合并冠脉病变者是否同期 PCI（一站式 TAVR＋PCI）、合并房颤者是否同期左心耳封堵 |

### 3.4 替代治疗方案

必须做**方案对比**，不能只列名称。逐项写：方案、适应证、本例适用性、主要风险、患者意愿与经济因素。

| 方案 | 要点 | 本例为何选／不选 |
|---|---|---|
| 外科主动脉瓣置换（SAVR） | 机械瓣／生物瓣；耐久性与抗凝代价；需体外循环 | 写明 STS-PROM／EuroSCORE II、胸廓条件、主动脉钙化、患者年龄与抗凝条件 |
| 药物治疗 | AS 无改善预后的药物；AR 以控制血压与心衰为主，重度 AR 慎用单纯血管扩张剂 | 写明已用药物、症状是否可控、为何不能替代干预 |
| 球囊主动脉瓣成形（BAV） | 桥接或姑息，再狭窄率高 | 写明是否作为桥接、姑息或急诊过渡 |
| 保守／姑息治疗 | 适用于预期寿命短、极度衰弱、患者拒绝 | 写明患者与家属意愿、伦理与安宁疗护讨论情况 |

### 3.5 麻醉方案

- **麻醉方式分层**：经股动脉入路**优选镇静或监护麻醉（MAC）**；特殊入路、危重患者、以及中心早期开展阶段**选择全身麻醉**；写明本例选择及理由。
- **监测**：有创动脉压、中心静脉压（按需）、经胸／经食管超声、脑氧饱和度、体温、尿量。
- **循环支持预案**：预防性植入 ECMO／IABP 的指征与决策人（心原性休克、血流动力学崩溃高风险、左室功能严重低下）。
- **麻醉风险**：ASA 分级及依据、困难气道评估、心功能与容量管理、肾功能与对比剂、术后拔管与镇痛方案。

### 3.6 可能出现的意外及防范措施

逐项写，**每项给"识别方式—预防措施—应急预案—责任人／设备"**；不得只罗列风险名称。

**术中：**

| 并发症 | 预防与识别 | 应急预案 |
|---|---|---|
| 循环崩溃（血流动力学崩溃） | 术前容量与心功能评估、麻醉诱导平稳、备循环辅助 | 立即药物支持、启动 ECMO／IABP、快速完成瓣膜释放 |
| 瓣周漏（中重度） | 瓣膜型号与超尺寸、后扩张策略、术中造影与超声评估 | 球囊后扩张、更换瓣膜、瓣中瓣、转外科 |
| 瓣膜移位／异位释放 | 钙化与瓣环评估、释放位置与角度、可回收系统 | 回收重释、第二枚瓣膜、转外科 |
| 冠状动脉闭塞／心肌梗死 | 冠脉开口高度与窦部宽度评估、瓣叶改造、冠脉保护导丝 | 紧急 PCI、冠脉支架、转外科搭桥 |
| 脑卒中／栓塞 | 神经系统风险评估、脑保护装置、抗栓管理 | 神经介入取栓、卒中绿色通道 |
| 血管并发症（破裂、夹层、血肿、假性动脉瘤、动静脉瘘） | 入路血管 CTA 评估、超声引导穿刺、预置缝合器 | 覆膜支架、外科修补、输血 |
| 传导阻滞（高度房室阻滞） | 术前心电图风险评估、临时起搏备用、瓣膜选择与释放位置 | 临时起搏、永久起搏器植入 |
| 心包积液／心包填塞 | 导丝操作规范、超声监测 | 心包穿刺引流、外科开窗 |
| 瓣环撕裂、主动脉夹层／撕裂 | 钙化与瓣环评估、避免过度超尺寸与过度后扩张 | 覆膜支架、转外科 |
| 二尖瓣功能损伤、左室—左房漏 | 导丝与器械位置确认 | 转外科修复 |
| 出血 | 抗栓停用与桥接、备血 | 输血、止血药物、外科止血 |

**术后：** 瓣膜血栓、感染性心内膜炎、急性肾损伤、卒中、新发房颤、传导阻滞需永久起搏器、残余瓣周漏、血管并发症、心衰加重、死亡。逐项写明监测手段（超声、心电图、肌钙蛋白、肾功能）、预防措施（抗栓方案、水化、早期活动）与随访节点。

## 四、主动脉瓣狭窄与主动脉瓣关闭不全的差异化判据

> 本节是模板的"判据附表"。AS 与 AR 共用第 3 章骨架，差异集中在本节；填写时**按病例类型取对应表**，混合性病变（AS 合并 AR）须同时对照两张表，并以病变主导类型决定主判据。

### 4.1 主动脉瓣狭窄（AS）手术指征判据

**（1）绝对适应证**（依据《中国经导管主动脉瓣置换术临床路径专家共识（2024 版）》核心观点 3）
前提：主动脉根部及入路解剖结构符合 TAVR（尤其经股动脉）要求，且**预期寿命 >1 年**。

| 序号 | 条件 |
|---|---|
| A1 | 年龄 ≥70 岁，重度 AS 且有 AS 所致症状：劳力性呼吸困难、心力衰竭、心绞痛、晕厥、既往或运动试验时晕厥先兆 |
| A2 | 运动试验可诱发症状或血压下降的**无症状**重度 AS |
| A3 | 无症状重度 AS，**LVEF <55%**（无其他原因导致的左室收缩功能不全） |
| A4 | 无症状重度 AS，LVEF >55%、运动试验正常、干预风险低，且满足以下之一：①极重度 AS（平均压差 ≥60 mmHg 或最大峰值流速 >5 m/s）；②重度瓣膜钙化（CT 评估）且最大峰值流速进展 ≥0.3 m/(s·年)；③重复检测确认、无其他诱因的 BNP 显著升高（＞性别、年龄校正正常值的 3 倍） |
| A5 | 年龄 <70 岁的重度 AS，存在外科手术禁忌或高危，或其他危险因素（胸部放射治疗后、肝功能衰竭、主动脉弥漫性严重钙化、极度虚弱等） |
| A6 | 外科主动脉生物瓣膜毁损（瓣中瓣） |

**（2）相对适应证**

| 序号 | 条件 |
|---|---|
| B1 | 年龄 60～69 岁，满足 A1～A4 之一，经心脏团队综合评估认为更适合 TAVR |
| B2 | 二叶式重度 AS 满足 A1～A4 之一，**在年手术量 ≥50 例的中心或年手术量 ≥25 例的术者**开展 |

**（3）重度 AS 的超声判定阈值**（写进"病变严重程度"段时必须给数值）

| 指标 | 重度 | 极重度 |
|---|---|---|
| 最大峰值流速 Vmax | ≥4.0 m/s | ≥5.0 m/s |
| 平均跨瓣压差 | ≥40 mmHg | ≥60 mmHg |
| 瓣口面积 AVA | ≤1.0 cm²（或 AVA 指数 ≤0.6 cm²/m²） | — |

> 低流速低梯度（LFLG）情形：AVA ≤1.0 cm²、平均压差 <40 mmHg、LVEF <50% 或每搏量指数 ≤35 mL/m² 时，须补充多巴酚丁胺负荷超声或 CT 钙化积分等评估，并在讨论中写明所用方法与结论。

### 4.2 主动脉瓣关闭不全（AR）手术指征判据

> **重要前提**：单纯 AR 的 TAVR 证据强度低于 AS，**属相对适应证**，必须在有经验中心、经心脏团队充分评估解剖适合性后决策；术前讨论中必须写明"为何外科手术不可行或高危"与"解剖为何适合 TAVR"。

**（1）有症状的重度单纯 AR（PAR）**：外科手术禁忌或高危、预期治疗后能临床获益、解剖特点经充分评估适合 TAVR，且在年手术量 ≥50 例的中心或年手术量 ≥25 例的术者开展。

**（2）无症状的重度 PAR**：外科手术禁忌或高危、预期获益、解剖适合，且满足以下**之一**：

| 序号 | 条件 |
|---|---|
| C1 | 左室舒张末期内径（LVEDD）>70 mm |
| C2 | 左室收缩末期内径（LVESD）>50 mm |
| C3 | LVESD 指数 >25 mm/m² |
| C4 | LVEF ≤55% |

> 阈值说明：C1～C4 为中国 TAVR 共识（2024）对无症状重度 PAR 行 TAVR 的表述；ESC 指南对**外科**干预的无症状阈值多为 LVEF ≤50% 或 LVESD >50 mm。两者不一致时，**以本院采用的指南版本为准，并在讨论记录中注明**。

**（3）重度 AR 的判定指标**（多参数综合，至少满足以下定量指标之一，具体阈值以本院超声报告与现行指南为准）

- 缩流颈宽度（VCW）≥6 mm
- 压力减半时间（PHT）<200 ms
- 反流容积 ≥60 mL/搏、反流分数 ≥50%
- 有效反流口面积 ≥0.30 cm²
- 左室扩大：LVEDD >70 mm（女性阈值更低）、LVESD >50 mm 或 LVESD 指数 >25 mm/m²

**（4）AR 的解剖锚定评估要点**（共识核心观点 28）

- 采用 **CT 双锚定多平面测量**，分别评估瓣环、左室流出道（LVOT）、升主动脉三处锚定条件；
- 解剖分型：**1 型**（瓣环、LVOT、升主动脉均可锚定）；**2 型**（LVOT 不能锚定，瓣环＋升主动脉可锚定）；**3 型**（瓣环＋LVOT 可锚定，升主动脉不能锚定）；**4 型**（三处均不能锚定）；
- 人工瓣膜在锚定平面的直径（周长）**超尺寸率应在 10% 以上**；
- 4 型患者原则上不适合常规 TAVR，须在讨论中明确说明替代方案。

### 4.3 共同禁忌证（必须逐条排除并写明依据）

1. 左心室内新鲜血栓；
2. 无纠正措施的左心室流出道严重梗阻；
3. 急性心肌梗死不稳定期；
4. 主动脉根部解剖形态不适合行 TAVR 治疗；
5. 存在其他严重合并症，即使纠正了主动脉瓣疾病仍预期寿命不足 1 年。

### 4.4 影像评估重点对比

| 维度 | AS | AR |
|---|---|---|
| 核心矛盾 | 瓣口狭窄与钙化 | 瓣叶对合不良、缺乏钙化锚定 |
| CT 重点 | 瓣环尺寸、钙化分布与积分、冠脉开口高度、窦部宽度、LVOT 钙化 | **双锚定平面测量**（瓣环／LVOT／升主动脉）＋解剖分型、超尺寸率 |
| 冠脉阻塞风险 | 钙化团块＋冠脉开口低→高风险 | 窦部扩张者风险相对低，但需逐个评估 |
| 传导阻滞风险 | 钙化累及 LVOT／瓣环、瓣膜支架深度 | 瓣膜型号与释放深度决定，需术前计划 |
| 破裂风险 | 钙化重、球囊过度扩张 | 瓣环扩张、缺乏钙化时锚定与破裂风险并存 |

### 4.5 风险侧重点对比

| 风险 | AS | AR |
|---|---|---|
| 瓣周漏 | 钙化结节导致贴合不良 | **更突出**（无钙化锚定、瓣环扩张） |
| 瓣膜移位 | 相对低（钙化提供锚定） | **更突出**（锚定不足） |
| 冠脉阻塞 | 钙化团块＋低冠脉开口 | 相对低，仍需评估 |
| 传导阻滞 | 钙化累及传导系统区域 | 与瓣膜支架深度相关 |
| 瓣环破裂 | 过度后扩张 | 瓣环扩张＋超尺寸需权衡 |
| 术后残余反流 | 中度以下可接受 | 需严密评估，残余中重度反流不可接受 |

### 4.6 器械与超尺寸策略对比

| 维度 | AS | AR |
|---|---|---|
| 瓣膜类型倾向 | 依钙化与二叶式选择球囊扩张式或自膨胀式 | 倾向锚定力强、可回收系统；必要时选用 AR 专用瓣膜 |
| 超尺寸计算 | 按瓣环面积／周长计算，避免过度超尺寸致破裂 | 按**锚定平面**直径（周长）计算，**≥10%** |
| 预扩张 | 钙化重者常需预扩张 | 多需预扩张评估锚定 |
| 后扩张 | 依残余瓣周漏决定 | 谨慎（易致移位或破裂） |

### 4.7 常见错误写法与纠正（反例）

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| "患者重度主动脉瓣狭窄，有手术指征" | 指征无依据、无判据 | "超声示 Vmax 〇〇 m/s、平均压差 〇〇 mmHg、AVA 〇〇 cm²，符合重度 AS；患者有劳力性呼吸困难（NYHA 〇级），符合绝对适应证 A1" |
| "拟行 TAVR 术" | 手术名称不规范、无入路无器械 | "拟行经导管主动脉瓣置换术（经〇〇侧股动脉入路），植入〇〇型瓣膜（规格〇〇 mm，依据瓣环周长 〇〇 mm、钙化分布〇〇）" |
| "风险：出血、感染、麻醉意外" | 泛化、与术式不匹配 | 按 TAVR 并发症谱逐项写，并给识别、预防、应急与责任人 |
| "麻醉：局麻" | TAVR 麻醉方式需按入路与病情分层 | "经〇〇入路，优选镇静／监护麻醉；本例因〇〇选择全身麻醉" |
| "资料未见异常" | 把资料缺口写成事实阴性 | "（该项资料未提供，待补充）" |
| 单纯 AR 未写解剖分型与超尺寸率 | 无法证明解剖适合性 | 写明双锚定测量值、分型（1～4 型）、超尺寸率（≥10%） |

①冠状动脉阻塞：左冠状动脉开口高度＿＿ mm 为临界，预防为备冠状动脉保护导丝、必要时行瓣叶改造，应急为紧急 PCI 或转外科搭桥，责任人为术者；②传导阻滞：瓣叶钙化累及瓣环，预防为控制释放深度、预置临时起搏电极，应急为临时起搏、必要时永久起搏器，责任人为术者与电生理组；③瓣周漏：预防为选择合适超尺寸、必要时后扩张，应急为更换瓣膜或瓣中瓣；④血管并发症：预防为超声引导穿刺、预置缝合器，应急为覆膜支架或血管外科修补；⑤循环崩溃：预防为麻醉平稳、备 ECMO，应急为药物支持与快速释放瓣膜；⑥急性肾损伤：预防为限制对比剂用量、围术期水化，术后监测肌酐。术后重点：抗栓方案为阿司匹林联合氯吡格雷 3～6 个月后转单药抗血小板；心电图监测 72 小时；术后 1 个月复查超声；随访 1 个月、6 个月、1 年。

## 七、系统落地建议（供信息科／厂商参考）

### 7.1 模板入库方式

- **新增独立模板**，命名"术前讨论记录-TAVR"，**不改动现有"术前讨论记录"模板**，避免影响其他术式；
- 运行时以数据库 `PROMPT_TEMPLATES` 中的记录为**唯一真实来源**；源码仓库中的模板文件与 GitHub 模板库仅作版本备份，须执行"双改"并核对运行时实际加载的版本；
- 模板正文**不得出现变量名／占位符**（如 `{{patientName}}`），否则前后端字段变更时需同步改模板，维护成本不可控。

### 7.2 与质控的关系

- 现有 `EMR-病历质控评估-术前讨论记录` 质控模板可继续复用；
- 建议在 TAVR 模板上线后，补充 TAVR 专项质控规则（对应本模板 5.2 的 T1～T12），作为术前讨论记录质控的"术式专项扩展"，而不是修改通用质控标准。

### 7.3 上线前验证清单

1. 以 3 份真实病例（AS 有症状、AS 无症状、AR 高危）跑通生成，人工比对"是否每一段都落到数值"；
2. 核对生成结果中**没有任何编造数值**（资料缺失处应为"（资料未提供，待补充）"）；
3. 核对手术名称、入路、瓣膜型号、麻醉方式在术前讨论／术前小结／知情同意书三处一致；
4. 核对质控评分不因模板切换而下降（对比切换前后同一病例的质控结果）。
