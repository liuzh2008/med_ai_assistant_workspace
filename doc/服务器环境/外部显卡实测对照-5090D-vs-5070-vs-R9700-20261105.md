## 四、口径差异（不可直接比较的原因）

| 差异项 | 我们 | 5090 D 截图 |
|---|---|---|
| **测量口径** | 端到端（含输入处理） | **引擎自报 decode** |
| **模型** | Q2_0（62 GB） | **IQ3_S（48.9 GB，小 21%）** |
| **上下文** | 短 | **262K** |
| **平台** | Windows | 未标注（推测 Windows） |

**换算关系**：引擎自报 decode 通常比端到端高 **15–30%**（本机实测结论）。

```
5090 D：144.5（decode）→ 端到端约 101–123
R9700：105.9（端到端）→ 反算 decode 约 122–138
```

**所以两者的真实差距在 0–20% 之间，不是“144.5 ÷ 105.9 = 36%”看起来的那么大。**

## 五、可能的解读

### 为什么 5090 D 的带宽是 2.7 倍，速度只快约 20%？

| 假设 | 说明 |
|---|---|
| GPU 负载仅 8% | 说明瓶颈不在显卡，在 CPU 调度或 MTP 生成 |
| 模型更小 | IQ3_S（48.9 GB）比 Q2_0（62 GB）小 21%，计算量更小但显存压力也更小 |
| 5090 D 是国行特供版 | D 版在算力上受限（符合出口管制的合规版本） |
| 单请求场景 | 单请求下 GPU 利用率天然低，多并发才能跑满 |

**结论：这张卡的性能没有被充分利用，或者说当前引擎/平台下无法把 1,792 GB/s 的带宽转化为速度。**

### 对我们决策的意义

| 判断 | 结论 |
|---|---|
| 5090 D 速度更快吗？ | ✅ 快 20% 左右（端到端换算后） |
| 值得买吗？ | ❌ **5 倍价格、20% 速度** |
| 1000 床要几台？ | 4 台（和 5070 一样，因为单台覆盖相近） |
| 4 台成本 | **18 万** vs 5070 的 7.3 万 |

## 六、对外沟通话术（被问"为什么不用 5090"时）

> 5090 D 单卡 4.5 万元，是 5070 的 5 倍。社区实测它的生成速度约 145 token/秒（引擎内部口径），折算成端到端约 110–125，比我们的 102.9 快 20% 左右。
>
> **多花 3.6 万元买 20% 速度，不划算。而且它单台同样只覆盖约 250 床，要覆盖 1000 床还是得 4 台——4 台 5090 D 是 18 万，4 台 5070 是 7.3 万。**
