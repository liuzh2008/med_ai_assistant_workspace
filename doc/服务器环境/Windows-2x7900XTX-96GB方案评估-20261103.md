## 三、可行性分析

### 3.1 为什么 2 卡能线性叠加

Strata 的多卡是**数据并行副本**（`serve/replicas.py`）：每卡加载一份完整模型，各自独立处理请求。MoE 副本之间**无通信、无同步**，所以吞吐近似线性。

```json
{ "gpus": [0, 1], "replicas": 2, "parallel": 8 }
```

### 3.2 为什么必须 96 GB 内存

社区实测明确：

> **XXS pack 26.9 GB** + 引擎自身，48 GB 机器跑 XXS 刚好；IQ3_S 的 pack 48.9 GB 在 48 GB 机器上开不了（可用 ~44 GB），要 64 GB 内存

2 副本 = **2 × 26.9 = 53.8 GB** 专家 pack 常驻内存，加系统和其他 ≈ **70 GB**。

- 62 GB（现状）→ ⚠️ 紧张
- **96 GB → ✅ 有余量**

### 3.3 为什么必须 IQ3_XXS 而不是 IQ3_S

同一份实测：

> IQ3_S：ctx 32768 + 无 MTP（**24G 显存装完 IQ3_S 专家只剩 592 MiB**）
> Monitor 实拍：`HIT 77% + PCIe 22%`

**24 GB 卡装 IQ3_S 后 expert cache 只剩 592 MiB**，decode 掉到 65。这是 24 GB 卡的红线。

### 3.4 平台支持状态

| 项 | 状态 |
|---|---|
| Windows rdna3 引擎包 | ✅ **存在**：`windows-x86_64-hip-rdna3`（gfx1100/1101/1102 + gfx1151），带 hipBLASLt 调优表，**未标注"未测试"** |
| 对比 rdna2 包 | 明确写 *"built, not tested on a real RX 6000 card"*，rdna3 **没有这句话** |
| gfx11 性能优化 | ⚠️ Strata 0.1.43 说明：*"RDNA3 (gfx11) and older keep their 0.1.42 behaviour: **we have no such card to measure on**"* |
| Windows + AMD 真卡 | ⚠️ 0.2.9 说明：*"Windows engines for ... RX 9070 ...: built and checked as packages, **not run through a model by us**"* |

**结论：功能支持，性能未针对性调优。**

## 四、为什么选 Windows 而不是 Linux

本机实测（同一张 R9700、同一模型）：

| 平台 | 单流 | 8 路聚合 | expert cache |
|---|---|---|---|
| **Windows** | **140** | **161** | 16384 slots / **21.6 GiB** |
| Linux | 84 | 121 | 6406 slots / 8.25 GiB |

**Windows 快 67%**，原因是 Windows 版引擎给了 2.6 倍的 expert cache。Linux 版有约 16 GiB 显存闲置未用（详见 [R9700-Linux-400tok每秒验证报告](R9700-Linux-400tok每秒验证报告-20261103.md)）。

**所以坚持 Windows 是对的**，但注意：这个优势是在 R9700 上测的，gfx11 上是否同样成立**未知**。

### 第 1 步：单卡验证（买 1 张，约 1 天）

| # | 检查项 | 通过标准 |
|---|---|---|

| 2 | Strata 引擎识别 | 加载 `windows-x86_64-hip-rdna3`（gfx1100） |
| 3 | 模型加载 | IQ3_XXS，`/health` 返回 `loaded: true` |
| 4 | expert cache | **≥ 15 GiB**（低于此命中率会崩） |
| 5 | **单流 decode** | **≥ 110 tok/s**（对照 Linux 的 117） |
| 6 | 命中率 | ≥ 90% |

**判定**：
- ✅ 单流 ≥ 110 → 买第 2 张
- ⚠️ 单流 90–110 → 勉强，2 卡约 180–220，可试
- ❌ 单流 < 90 → **止损**，退货或转卖

## 八、结论

**这个方案是达成 200 tok/s 最便宜的路径，支持执行，但必须分两步走。**

**核心逻辑**：

1. **产能达标**：2 卡副本 = 2 × 117 = 234 tok/s（保守），过 200 有余量
2. **成本可控**：净支出约 2,300–4,300 元（卖 R9700 后），每元产能提升 66%
3. **平台正确**：Windows 比 Linux 快 67%（有本机实测支撑）
4. **最大风险**：Windows + gfx11 是官方未验证组合，必须**先验 1 张**

**一句话**：**花不到 5 千，产能从 140 到 234+；但先买 1 张验，别一次买 2 张。**
