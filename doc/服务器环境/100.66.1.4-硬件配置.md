## 7. 复现命令

```bash
ssh testserver "hostname; date; uptime; uptime -s"
ssh testserver "lscpu | head -22"
ssh testserver "free -h; head -8 /proc/meminfo; swapon --show"
ssh testserver "df -h /; lsblk"
ssh testserver "for z in /sys/class/thermal/thermal_zone*; do [ -e \$z/temp ] && echo \"\$(cat \$z/type): \$(( \$(cat \$z/temp)/1000 ))C\"; done"
ssh testserver "cat /sys/class/power_supply/BAT0/capacity /sys/class/power_supply/BAT0/status"
```

> 提示：经 PowerShell→ssh 传参时，含引号/括号的远端命令会被吞引号导致 bash 语法错误，
> 建议把远端命令写入 `.sh` 脚本后 `Get-Content -Raw x.sh | ssh testserver "tr -d '\r' | bash -s"` 执行。

原始采集输出：`temp/hw-status.log`（工作区临时目录，可清理）
