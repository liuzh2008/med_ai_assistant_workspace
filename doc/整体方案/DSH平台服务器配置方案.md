# DSH 平台服务器配置方案（台式机采购清单）

> 状态：定稿（2026-09-07，用户决策：DSH 平台 + MedAi 全家桶同机；Ubuntu Server 24.04 直装；主力档预算 7000-10000 元）
> 定位：正式生产承载机（替代方案 v1.3 §6 阶段 2 中"几十人正式承载机待定"），可达 iptables/容器隔离的 Linux 达标形态；本机 Windows 63.8GB 继续做试点主环境；100.66.1.4 降为 Linux 形态验证备机。

## 1. 负载画像（据《DSH服务器化多租户平台架构方案》§4.6）

| 负载 | 量级 | 硬件要求 |
|---|---|---|
| MedAi 全家桶（同机） | ~6-8GB（100.66.1.4 容器实测口径：Oracle 21c XE、main、execution、redis、前端） | 内存；Java 多核 |
| DSH 实例池（近期） | 16-32 池 / 10-30 并发 ≈ 10-16GB | 内存瓶颈（~0.35GB/实例基线，阶段 0 实测校准） |
| DSH 实例池（远期 1 shard） | 50-80 池 ≈ 25-40GB | 内存扩容路线：64GB → 128GB |
| LLM 推理 | 不在本机（MedAi llmproxy/DeepSeek 出口） | 无需高端 CPU/GPU |
| 会话写入 | JSONL zstd 高频追加 | NVMe 必须 |

## 2. 配置清单（主力档）

| 组件 | 选型 | 备注 |
|---|---|---|
| CPU | AMD Ryzen 9 7900X（12C/24T） | 可选升级 7950X（16C/32T） |
| 主板 | B650E，4×DDR5 槽 | 内存扩展核心：2×32 起步 → 插满 128GB |
| 内存 | DDR5-5600 64GB（2×32GB） | 近期从容；远期补 2×32 至 128GB |
| 系统盘 | NVMe PCIe4.0 1TB | OS + 共享 DSH 代码（只读） |
| 数据盘 | NVMe 2TB（独立盘） | users/ 会话 + MedAi 容器 volume |
| 备份盘 | 4TB HDD 或 NAS | 每日增量备份，独立于数据盘 |
| 电源 | 750W 金牌 | 7×24 常驻 |
| 散热/机箱 | 塔式风冷；机箱 ≥3 盘位 | 长期散热冗余 |
| UPS | 在线式 1kVA（强烈建议） | 断电/写入中断防护 |
| 网络 | 板载 2.5GbE | 内网余量 |
| 系统 | Ubuntu Server 24.04 LTS | headless；BIOS 设断电来电自启 |
| 远程 | SSH + 向日葵/AweSun | 消费级无 IPMI |

## 3. 容量对应

- 近期同机：MedAi ~6-8GB + DSH 池 10-16GB + 系统余量 ≈ 64GB 从容。
- 远期同机（1 shard）：MedAi ~8GB + 池 25-40GB ≈ 64GB 吃紧 → 补至 128GB（4 槽插满即达，无主板更换）。

## 4. 预算

- 不含 UPS：约 7500-9500 元（2026-09 市场参考，以实际为准）。
- UPS：约 1000 元另计。

## 5. 采购与装机注意事项

1. 确认 CPU/主板组合支持 4×DDR5 满插稳定（查主板 QVL）。
2. 机箱需 ≥3 盘位（2 NVMe + 1 HDD）；NVMe 散热片齐备。
3. 数据盘与备份盘不同物理盘；上线后即配每日备份任务。
4. 装机后按《DSH生产部署指南.md》装 DSH + Docker（MedAi 容器）+ 方案 §3.2 目录布局初始化。
5. 接入内网前先完成：SSH 加固、UFW 白名单、审计日志、UPS 联动关机。
